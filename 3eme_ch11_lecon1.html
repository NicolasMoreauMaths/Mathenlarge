I. Résoudre une équation du premier degré à une inconnue
1) Ranger les termes : la boîte des lettres et la boîte des nombres
💡 Idée

Pour résoudre une équation, on apprend d'abord à ranger les termes : d'un côté les termes qui contiennent la lettre \(x\), de l'autre les nombres seuls.

✏️ Exemple
Range chacun des termes suivants dans la bonne boîte.
\(3x\)  ;  \(-8\)  ;  \(-x\)  ;  \(12\)  ;  \(7x\)  ;  \(-5\)  ;  \(x\)  ;  \(-9x\)
🟥 La boîte des lettres
à compléter…
🟩 La boîte des nombres
à compléter…
🟥 La boîte des lettres
\(3x\)\(-x\)\(7x\)\(x\)\(-9x\)
🟩 La boîte des nombres
\(-8\)\(12\)\(-5\)
Pour résoudre une équation, on regroupe les termes en \(x\) d'un côté et les nombres de l'autre : savoir trier, c'est déjà savoir quoi supprimer à chaque étape.
2) Résoudre une équation du premier degré
💡 Méthode

On isole \(x\) en appliquant la même opération aux deux membres de l'équation, une étape à la fois. On repère le terme à supprimer (en rouge) et on applique l'opération inverse à gauche et à droite (les deux flèches).

✏️ Exemples
Résoudre les équations suivantes (de plus en plus complètes).
  • a)\(x + 7 = 12\)
  • b)\(3x = 18\)
  • c)\(2x + 5 = 17\)
  • d)\(5x - 3 = 2x + 9\)
  • e)\(5(x - 3) = 3x + 1\)
  • f)\(7 - 2x = 15\)
a) \(x + 7 = 12\)
\(x +\) \(7\) \(= 12\)
\(-7\)
\(-7\)
\(x = 5\)
La solution est \(x = 5\).
b) \(3x = 18\)
\(3\)\(x = 18\)
\(\div 3\)
\(\div 3\)
\(x = 6\)
La solution est \(x = 6\).
c) \(2x + 5 = 17\)
\(2x +\) \(5\) \(= 17\)
\(-5\)
\(-5\)
\(2\)\(x = 12\)
\(\div 2\)
\(\div 2\)
\(x = 6\)
La solution est \(x = 6\).
d) \(5x - 3 = 2x + 9\)
\(5x - 3 =\) \(2x\) \(+ 9\)
\(-2x\)
\(-2x\)
\(3x\) \(-3\) \(= 9\)
\(+3\)
\(+3\)
\(3\)\(x = 12\)
\(\div 3\)
\(\div 3\)
\(x = 4\)
La solution est \(x = 4\).
e) \(5(x - 3) = 3x + 1\)
\(5(x - 3) = 3x + 1\)
On développe le membre de gauche :
\(5x - 15 =\) \(3x\) \(+ 1\)
\(-3x\)
\(-3x\)
\(2x\) \(-15\) \(= 1\)
\(+15\)
\(+15\)

\(\div 2\)
\(\div 2\)
\(x = 8\)
La solution est \(x = 8\).
f) \(7 - 2x = 15\)
\(7\) \(- 2x = 15\)
\(-7\)
\(-7\)
\(-2\)\(x = 8\)
\(\div(-2)\)
\(\div(-2)\)
\(x = -4\)
La solution est \(x = -4\).
👉 Ici, à la fin, on a divisé les deux membres par \(-2\) : on peut donc diviser par un nombre négatif. Pour une équation, cela ne pose aucun problème — on le retrouvera (avec une précaution !) pour les inéquations.
3) Équations particulières : l'égalité des produits en croix
📗 Propriété

Quels que soient les nombres \(a, b, c\) et \(d\) (avec \(b \neq 0\) et \(d \neq 0\)) :

Si \(\dfrac{a}{b} = \dfrac{c}{d}\),   alors \(a \times d = b \times c\).
✏️ Exemples
Résoudre les équations suivantes.
  • a)\(\dfrac{x}{4} = \dfrac{9}{6}\)
  • b)\(\dfrac{5}{AB} = \dfrac{3}{2}\)
a) \(\dfrac{x}{4} = \dfrac{9}{6}\)
Produit en croix : \(x \times 6 = 4 \times 9\), soit \(6x = 36\).
\(6\)\(x = 36\)
\(\div 6\)
\(\div 6\)
\(x = 6\)
La solution est \(x = 6\).
b) \(\dfrac{5}{AB} = \dfrac{3}{2}\)
Produit en croix : \(5 \times 2 = 3 \times AB\), soit \(3 \times AB = 10\).
\(3\) \(\times AB = 10\)
\(\div 3\)
\(\div 3\)
\(AB = \dfrac{10}{3}\)
\(AB = \dfrac{10}{3} \approx 3{,}33\) (on laisse la valeur exacte sous forme de fraction).
4) Modéliser un problème par une équation
📝 Méthode — à suivre à chaque fois
  1. On choisit l'inconnue \(x\) en fonction de ce que l'on cherche.
  2. On traduit les données de l'énoncé par une équation.
  3. On résout l'équation.
  4. On interprète le résultat (on répond à la question posée).
✏️ Exemple
Deux salles d'escalade proposent chacune un tarif.
• Salle A : 30 € d'inscription, puis 4 € par séance.
• Salle B : 10 € d'inscription, puis 6 € par séance.
Pour combien de séances paie-t-on le même prix dans les deux salles ?

Étape 1 On pose \(x\) = le nombre de séances.

Étape 2 Prix dans la salle A : \(30 + 4x\). Prix dans la salle B : \(10 + 6x\). On cherche quand ils sont égaux :

\(30 + 4x = 10 + 6x\)

Étape 3 On résout :

\(30 +\) \(4x\) \(= 10 + 6x\)
\(-4x\)
\(-4x\)
\(30 =\) \(10\) \(+ 2x\)
\(-10\)
\(-10\)
\(20 =\) \(2\)\(x\)
\(\div 2\)
\(\div 2\)
\(10 = x\)
Étape 4 — Réponse :Les deux salles coûtent le même prix pour 10 séances (soit \(70\) € dans chaque salle).
II. Résoudre une inéquation du premier degré
1) On procède comme pour une équation
💡 Méthode

Résoudre une inéquation, c'est trouver tous les nombres \(x\) qui vérifient une condition écrite avec un symbole \(<\,,\ >\,,\ \le\) ou \(\ge\). On utilise les mêmes opérations que pour une équation.

✏️ Exemples
Résoudre les inéquations suivantes.
  • a)\(x + 4 < 9\)
  • b)\(3x \ge 12\)
  • c)\(2x + 1 \le 7\)
  • d)\(5x - 2 > 3x + 6\)
a) \(x + 4 < 9\)
\(x +\) \(4\) \(< 9\)
\(-4\)
\(-4\)
\(x < 5\)
Solutions : tous les nombres \(x < 5\).
b) \(3x \ge 12\)
\(3\)\(x \ge 12\)
\(\div 3\)
\(\div 3\)
\(x \ge 4\)
Solutions : tous les nombres \(x \ge 4\).
c) \(2x + 1 \le 7\)
\(2x +\) \(1\) \(\le 7\)
\(-1\)
\(-1\)
\(2\)\(x \le 6\)
\(\div 2\)
\(\div 2\)
\(x \le 3\)
Solutions : tous les nombres \(x \le 3\).
d) \(5x - 2 > 3x + 6\)
\(5x - 2 >\) \(3x\) \(+ 6\)
\(-3x\)
\(-3x\)
\(2x\) \(-2\) \(> 6\)
\(+2\)
\(+2\)
\(2\)\(x > 8\)
\(\div 2\)
\(\div 2\)
\(x > 4\)
Solutions : tous les nombres \(x > 4\).
2) Le piège : multiplier ou diviser par un nombre négatif
⚠ Propriété à retenir

Quand on multiplie ou divise les deux membres d'une inéquation par un nombre négatif, on doit changer le sens de l'inéquation :

\(\le\) devient \(\ge\)   ,   \(<\) devient \(>\)  (et inversement).

Ajouter ou soustraire ne change jamais le sens.

✏️ Exemples
Résoudre ces inéquations (attention au signe !).
  • a)\(-2x \ge 8\)
  • b)\(-x + 3 < 5\)
  • c)\(4 - 3x \le 16\)
  • d)\(2x + 7 > 5x - 2\)
a) \(-2x \ge 8\)
\(-2\)\(x \ge 8\)
⚠ On divise par \(-2\) (négatif) : on change le sens.
\(\div(-2)\)
\(\div(-2)\)
\(x \le -4\)  (\(\ge \to \le\))
Solutions : tous les nombres \(x \le -4\).
b) \(-x + 3 < 5\)
\(-x +\) \(3\) \(< 5\)
\(-3\)
\(-3\)
\(-1\)\(x < 2\)
⚠ On divise par \(-1\) (négatif) : on change le sens.
\(\div(-1)\)
\(\div(-1)\)
\(x > -2\)  (\(< \to >\))
Solutions : tous les nombres \(x > -2\).
c) \(4 - 3x \le 16\)
\(4\) \(- 3x \le 16\)
\(-4\)
\(-4\)
\(-3\)\(x \le 12\)
⚠ On divise par \(-3\) (négatif) : on change le sens.
\(\div(-3)\)
\(\div(-3)\)
\(x \ge -4\)  (\(\le \to \ge\))
Solutions : tous les nombres \(x \ge -4\).
d) \(2x + 7 > 5x - 2\)
\(2x + 7 >\) \(5x\) \(- 2\)
\(-5x\)
\(-5x\)
\(-3x +\) \(7\) \(> -2\)
\(-7\)
\(-7\)
\(-3\)\(x > -9\)
⚠ On divise par \(-3\) (négatif) : on change le sens.
\(\div(-3)\)
\(\div(-3)\)
\(x < 3\)  (\(> \to <\))
Solutions : tous les nombres \(x < 3\).
III. Résoudre une équation du type \(x^2 = a\)
📗 Propriété

L'équation \(x^2 = a\) admet :

si \(a > 0\)deux solutions
\(x = -\sqrt{a}\) et \(x = \sqrt{a}\)
si \(a = 0\)une seule solution
\(x = 0\)
si \(a < 0\)aucune solution
📘 Rappel — racine carrée

La racine carrée de \(a\) (notée \(\sqrt{a}\)) est le nombre positif dont le carré vaut \(a\). Un carré n'étant jamais négatif, l'équation n'a aucune solution lorsque \(a < 0\).

✏️ Exemples
Résoudre les équations suivantes.
  • a)\(x^2 = 49\)
  • b)\(x^2 = 10\)
  • c)\(x^2 = -16\)
  • d)\(x^2 = 0\)
  • e)\(x^2 - 15 = 0\)
  • f)\(2x^2 = 72\)
a) \(x^2 = 49\)
\(49 > 0\) : deux solutions, et \(\sqrt{49} = 7\).
\(x = -7\) ou \(x = 7\).
b) \(x^2 = 10\)
\(10 > 0\) : deux solutions. \(\sqrt{10}\) ne tombe pas juste, on garde la valeur exacte.
\(x = -\sqrt{10}\) ou \(x = \sqrt{10}\)  (\(\approx \pm 3{,}16\)).
c) \(x^2 = -16\)
\(-16 < 0\) : un carré n'est jamais négatif.
Aucune solution.
d) \(x^2 = 0\)
\(a = 0\) : une seule solution.
\(x = 0\).
e) \(x^2 - 15 = 0\)
On isole d'abord \(x^2\) :
\(x^2\) \(-15\) \(= 0\)
\(+15\)
\(+15\)
\(x^2 = 15\)
\(x = -\sqrt{15}\) ou \(x = \sqrt{15}\).
f) \(2x^2 = 72\)
On isole d'abord \(x^2\) :
\(2\)\(x^2 = 72\)
\(\div 2\)
\(\div 2\)
\(x^2 = 36\)
\(x = -6\) ou \(x = 6\)  (car \(\sqrt{36} = 6\)).
