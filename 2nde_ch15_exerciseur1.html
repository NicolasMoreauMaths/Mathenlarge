Afficher un message — print()

En Python, pour afficher quelque chose à l'écran, on utilise la commande print().
On écrit ce qu'on veut afficher entre les parenthèses.

📘 À retenir

Pour afficher du texte, on le met entre guillemets : "Bonjour"
Pour afficher un nombre, on l'écrit directement : 42

🔍 Exemple
exemple1.py
print("Bonjour !")
print(42)
Ligne 1 → Python affiche : Bonjour !
Ligne 2 → Python affiche : 42

Stocker une valeur — les variables

Une variable, c'est comme une boîte dans la mémoire de l'ordinateur. On lui donne un nom et on y range une valeur.

Pour ranger une valeur, on utilise le signe =. On appelle ça une affectation.

📘 Syntaxe

nom_de_variable = valeur

Le nom est à gauche, la valeur à droite.

🔍 Exemple
exemple2.py
age = 16
print(age)
Ligne 1 → Python crée une boîte appelée age et y range le nombre 16.
Ligne 2 → Python ouvre la boîte age et affiche son contenu : 16
⚠️ AttentionDans print(age), il n'y a pas de guillemets autour de age. Avec guillemets, Python afficherait le mot « age ». Sans guillemets, il affiche le contenu de la boîte (16).

Calculer — les opérations

Python sait faire des calculs. La plupart des symboles ressemblent aux mathématiques, mais il y a deux différences importantes.

📘 Les opérateurs
+ addition
- soustraction
* multiplication
/ division
** puissance ⚠️
% reste ⚠️
⚠️ Attention — la puissance

En mathématiques on écrit 23. En Python on écrit 2 ** 3 (deux étoiles).
Le symbole ^ ne fonctionne pas pour la puissance en Python !

🔍 Exemple
exemple3.py
print(3 + 5)    # affiche 8
print(10 - 4)   # affiche 6
print(2 ** 3)   # affiche 8  (2³)
print(10 % 3)   # affiche 1  (reste de 10÷3)

Combiner — variables et calculs

On peut stocker le résultat d'un calcul dans une variable, et utiliser des variables dans des calculs.

🔍 Exemple — Calcul du prix total
prix.py
prix_unitaire = 8
quantite = 3
total = prix_unitaire * quantite
print(total)
Ligne 1 → Boîte prix_unitaire contient 8
Ligne 2 → Boîte quantite contient 3
Ligne 3 → Python calcule 8 × 3 = 24, range 24 dans total
Ligne 4 → Python affiche : 24
