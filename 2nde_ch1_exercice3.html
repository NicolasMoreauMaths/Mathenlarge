√ Les Racines carrées

Calculs de tête · Encadrement · Valeur absolue · Formules

2nde 8 exercices Chapitre 1 · Calcul numérique
📖 Rappels
Définition
Pour \(a \geq 0\), \(\sqrt{a}\) est l'unique réel positif dont le carré vaut \(a\).
\(\left(\sqrt{a}\right)^2 = a\)   et   \(\sqrt{a^2} = |a|\)
Formules
\(\sqrt{a \times b} = \sqrt{a} \times \sqrt{b}\)
\(\sqrt{\dfrac{a}{b}} = \dfrac{\sqrt{a}}{\sqrt{b}}\)  (\(b \neq 0\))
⚠️ \(\sqrt{a+b} \neq \sqrt{a}+\sqrt{b}\)
Valeur absolue
\(|x| = x\) si \(x \geq 0\)
\(|x| = -x\) si \(x < 0\)
\(\sqrt{x^2} = |x|\)   \(|ab| = |a||b|\)

Partie 1 – Calculs et encadrement

Exercice 1 / 8

Racines carrées calculées de tête
✓ Vu
Calcule sans calculatrice. Les résultats sont des entiers.
a) \(\sqrt{49} =\)
b) \(\sqrt{9} =\)
c) \(\sqrt{144} =\)
d) \(\sqrt{25} =\)
e) \(\sqrt{1} =\)
f) \(\sqrt{81} =\)
g) \(\sqrt{36} =\)
h) \(\sqrt{121} =\)
i) \(\sqrt{16} =\)
j) \(\sqrt{64} =\)
k) \(\sqrt{4} =\)
l) \(\sqrt{100} =\)
💡 Indices
Demande-toi : « quel entier, élevé au carré, donne \(n\) ? » Par exemple, \(\sqrt{49} = 7\) car \(7^2 = 49\). Ce sont les carrés parfaits à connaître par cœur.
a) \(\sqrt{49} = 7\)   b) \(\sqrt{9} = 3\)   c) \(\sqrt{144} = 12\)   d) \(\sqrt{25} = 5\)
e) \(\sqrt{1} = 1\)   f) \(\sqrt{81} = 9\)   g) \(\sqrt{36} = 6\)   h) \(\sqrt{121} = 11\)
i) \(\sqrt{16} = 4\)   j) \(\sqrt{64} = 8\)   k) \(\sqrt{4} = 2\)   l) \(\sqrt{100} = 10\)
🔑 Ces 12 valeurs sont les carrés parfaits à connaître absolument. Elles servent de références pour encadrer toutes les autres racines.

Exercice 2 / 8

Encadrement de racines carrées par des entiers
✓ Vu
Sans calculatrice, encadre chaque racine carrée par deux entiers consécutifs.
Exemple : \(\ldots < \sqrt{20} < \ldots\)
a) \(< \sqrt{5} <\)
b) \(< \sqrt{15} <\)
c) \(< \sqrt{30} <\)
d) \(< \sqrt{50} <\)
e) \(< \sqrt{75} <\)
f) \(< \sqrt{110} <\)
💡 Indices
Cherche les deux carrés parfaits consécutifs qui encadrent le nombre sous la racine. Par exemple, pour \(\sqrt{20}\) : comme \(16 < 20 < 25\), on a \(4 < \sqrt{20} < 5\).
a) \(2^2 = 4 < 5 < 9 = 3^2\), donc \(\mathbf{2 < \sqrt{5} < 3}\)
b) \(3^2 = 9 < 15 < 16 = 4^2\), donc \(\mathbf{3 < \sqrt{15} < 4}\)
c) \(5^2 = 25 < 30 < 36 = 6^2\), donc \(\mathbf{5 < \sqrt{30} < 6}\)
d) \(7^2 = 49 < 50 < 64 = 8^2\), donc \(\mathbf{7 < \sqrt{50} < 8}\)
e) \(8^2 = 64 < 75 < 81 = 9^2\), donc \(\mathbf{8 < \sqrt{75} < 9}\)
f) \(10^2 = 100 < 110 < 121 = 11^2\), donc \(\mathbf{10 < \sqrt{110} < 11}\)
🔑 Pour encadrer \(\sqrt{n}\) : trouve les deux carrés parfaits \(k^2\) et \((k+1)^2\) tels que \(k^2 < n < (k+1)^2\). Alors \(k < \sqrt{n} < k+1\).

Partie 2 – Valeur absolue

Exercice 3 / 8

Notion de valeur absolue
✓ Vu
a) à f) Calcule la valeur absolue.
g) à j) Simplifie \(\sqrt{x^2}\) selon le signe de \(x\).
a) \(|7| =\)
b) \(|-5| =\)
c) \(|-\sqrt{3}| =\)
d) \(|3 - 7| =\)
e) \(|\pi - 4| =\)
f) \(|\sqrt{2} - 1| =\)
g) \(\sqrt{(-3)^2} =\)
h) \(\sqrt{(2-5)^2} =\)
💡 Indices
\(|x|\) est la distance de \(x\) à 0 sur la droite des réels. C'est toujours un nombre positif ou nul. Si \(x\) est négatif, \(|x| = -x\) (on change le signe).
Pour \(|\pi - 4|\) : comme \(\pi \approx 3{,}14 < 4\), l'expression \(\pi - 4\) est négative. Donc \(|\pi - 4| = -(\pi - 4) = 4 - \pi\). Même raisonnement pour \(|\sqrt{2} - 1|\) : \(\sqrt{2} \approx 1{,}41 > 1\), donc…
a) \(|7| = 7\)   b) \(|-5| = 5\)   c) \(|-\sqrt{3}| = \sqrt{3}\)
d) \(|3-7| = |-4| = 4\)
e) \(\pi \approx 3{,}14 < 4\), donc \(\pi - 4 < 0\), d'où \(|\pi - 4| = 4 - \pi\)
f) \(\sqrt{2} \approx 1{,}41 > 1\), donc \(\sqrt{2} - 1 > 0\), d'où \(|\sqrt{2} - 1| = \sqrt{2} - 1\)
g) \(\sqrt{(-3)^2} = \sqrt{9} = 3 = |-3|\)
h) \(\sqrt{(2-5)^2} = \sqrt{(-3)^2} = \sqrt{9} = 3 = |2-5|\)
🔑 \(\sqrt{x^2} = |x|\), jamais \(x\) tout court ! Si \(x\) peut être négatif, le résultat n'est pas \(x\) mais \(|x|\).
⚠️ Erreur fréquente : \(\sqrt{(-3)^2} \neq -3\). Une racine carrée est toujours positive ou nulle.

Partie 3 – Formules de racines carrées

Exercice 4 / 8

Formules · simplification de racines
✓ Vu
Simplifie chaque expression en l'écrivant sous la forme \(\ldots\sqrt{\ldots}\), où le nombre sous la racine est le plus petit possible. Si le résultat est un entier, écris simplement cet entier.
a) \(\sqrt{12} =\)
b) \(\sqrt{50} =\)
c) \(\sqrt{75} =\)
d) \(\sqrt{200} =\)
e) \(\sqrt{72} =\)
f) \(\sqrt{98} =\)
g) \(\sqrt{45} =\)
h) \(\sqrt{300} =\)
💡 Indices
Cherche un facteur carré parfait dans le nombre. Par exemple \(12 = 4 \times 3\), donc \(\sqrt{12} = \sqrt{4 \times 3} = \sqrt{4} \times \sqrt{3} = 2\sqrt{3}\). Prends le plus grand carré parfait possible.
a) \(\sqrt{12} = \sqrt{4 \times 3} = \sqrt{4} \times \sqrt{3} = 2\sqrt{3}\)
b) \(\sqrt{50} = \sqrt{25 \times 2} = \sqrt{25} \times \sqrt{2} = 5\sqrt{2}\)
c) \(\sqrt{75} = \sqrt{25 \times 3} = 5\sqrt{3}\)
d) \(\sqrt{200} = \sqrt{100 \times 2} = 10\sqrt{2}\)
e) \(\sqrt{72} = \sqrt{36 \times 2} = 6\sqrt{2}\)
f) \(\sqrt{98} = \sqrt{49 \times 2} = 7\sqrt{2}\)
g) \(\sqrt{45} = \sqrt{9 \times 5} = 3\sqrt{5}\)
h) \(\sqrt{300} = \sqrt{100 \times 3} = 10\sqrt{3}\)
🔑 \(\sqrt{a \times b} = \sqrt{a} \times \sqrt{b}\). Pour simplifier, on extrait le plus grand carré parfait qui divise le nombre sous la racine.

Exercice 5 / 8

Formules · produit et quotient
✓ Vu
Simplifie chaque expression. On ne cherche pas à calculer une valeur décimale : le résultat est un entier ou une expression avec des racines.
a) \(\sqrt{3} \times \sqrt{3} =\)
b) \(\sqrt{5} \times \sqrt{20} =\)
c) \(\sqrt{6} \times \sqrt{6} =\)
d) \(\sqrt{2} \times \sqrt{8} =\)
e) \(\dfrac{\sqrt{18}}{\sqrt{2}} =\)
f) \(\dfrac{\sqrt{75}}{\sqrt{3}} =\)
g) \((\sqrt{7})^2 =\)
h) \(\sqrt{2} \times \sqrt{3} \times \sqrt{6} =\)
💡 Indices
\(\sqrt{a} \times \sqrt{a} = (\sqrt{a})^2 = a\). La racine et le carré s'annulent. De même \(\sqrt{a} \times \sqrt{b} = \sqrt{a \times b}\) : regroupe sous une seule racine.
\(\dfrac{\sqrt{a}}{\sqrt{b}} = \sqrt{\dfrac{a}{b}}\). Regroupe sous une seule racine et simplifie la fraction avant de calculer.
a) \(\sqrt{3} \times \sqrt{3} = (\sqrt{3})^2 = 3\)
b) \(\sqrt{5} \times \sqrt{20} = \sqrt{5 \times 20} = \sqrt{100} = 10\)
c) \(\sqrt{6} \times \sqrt{6} = 6\)
d) \(\sqrt{2} \times \sqrt{8} = \sqrt{16} = 4\)
e) \(\dfrac{\sqrt{18}}{\sqrt{2}} = \sqrt{\dfrac{18}{2}} = \sqrt{9} = 3\)
f) \(\dfrac{\sqrt{75}}{\sqrt{3}} = \sqrt{\dfrac{75}{3}} = \sqrt{25} = 5\)
g) \((\sqrt{7})^2 = 7\)
h) \(\sqrt{2} \times \sqrt{3} \times \sqrt{6} = \sqrt{2 \times 3 \times 6} = \sqrt{36} = 6\)
🔑 \(\sqrt{a} \times \sqrt{b} = \sqrt{ab}\) et \((\sqrt{a})^2 = a\). Ces deux identités permettent de simplifier sans calculatrice.

Exercice 6 / 8

Formules · valeur absolue
✓ Vu
Simplifie chaque expression en utilisant \(\sqrt{x^2} = |x|\). Pour chaque question, commence par déterminer le signe de ce qui est sous la racine.
a) \(\sqrt{x^2}\) pour \(x \geq 0\) :
b) \(\sqrt{x^2}\) pour \(x < 0\) :
c) \(\sqrt{9x^2}\) :
d) \(\sqrt{(x-3)^2}\) :
e) \(\sqrt{(x-3)^2}\) pour \(x \geq 3\) :
f) \(\sqrt{(x-3)^2}\) pour \(x < 3\) :
💡 Indices
La racine carrée donne toujours un résultat positif. Si \(x \geq 0\), alors \(|x| = x\). Si \(x < 0\), alors \(|x| = -x\) (ce qui est bien positif puisqu'on change le signe d'un nombre négatif).
\(9x^2 = (3x)^2\). On peut donc appliquer directement \(\sqrt{(3x)^2} = |3x|\). Comme \(3 > 0\), on a \(|3x| = 3|x|\).
En e), si \(x \geq 3\), alors \(x - 3 \geq 0\), donc \(|x-3| = x-3\). En f), si \(x < 3\), alors \(x - 3 < 0\), donc \(|x-3| = -(x-3) = 3-x\).
a) Si \(x \geq 0\) : \(\sqrt{x^2} = |x| = x\)
b) Si \(x < 0\) : \(\sqrt{x^2} = |x| = -x\)  (car \(-x > 0\) quand \(x < 0\))

c) On écrit \(9x^2 = (3x)^2\), donc :
\(\sqrt{9x^2} = \sqrt{(3x)^2} = |3x| = 3|x|\)

d) Sans information sur le signe de \(x - 3\), on ne peut pas simplifier davantage :
\(\sqrt{(x-3)^2} = |x-3|\)

e) Si \(x \geq 3\), alors \(x - 3 \geq 0\), donc \(|x-3| = x - 3\) :
\(\sqrt{(x-3)^2} = x - 3\)

f) Si \(x < 3\), alors \(x - 3 < 0\), donc \(|x-3| = -(x-3) = 3 - x\) :
\(\sqrt{(x-3)^2} = 3 - x\)
🔑 \(\sqrt{A^2} = |A|\) toujours. Pour lever la valeur absolue, il faut connaître le signe de \(A\). Sans cette information, le résultat s'écrit avec des barres \(|\cdot|\).
⚠️ Erreur fréquente : écrire \(\sqrt{(x-3)^2} = x-3\) sans vérifier que \(x \geq 3\). Si \(x = 1\) par exemple, \(\sqrt{(1-3)^2} = \sqrt{4} = 2\), et non \(1-3 = -2\).

Partie 4 – Problèmes

Exercice 7 / 8

Problème · formules de racines ⚠️ Difficile
✓ Vu
📐 Un carré a une aire de 48 cm².
a) Exprime la longueur de son côté sous la forme \(\ldots\sqrt{\ldots}\), avec le nombre sous la racine le plus petit possible.
b) Un second carré a une aire quatre fois plus grande. Exprime son côté sous la forme \(\ldots\sqrt{\ldots}\), puis compare avec le premier.
c) Calcule le périmètre du premier carré sous la forme \(\ldots\sqrt{\ldots}\).
💡 Indices
Si le côté mesure \(c\), l'aire vaut \(c^2\). Donc \(c = \sqrt{\text{aire}}\). Simplifie ensuite \(\sqrt{48}\) en cherchant le plus grand carré parfait qui divise 48.
Si l'aire est multipliée par 4, le côté est multiplié par \(\sqrt{4} = 2\). On peut aussi calculer directement \(\sqrt{4 \times 48} = \sqrt{4} \times \sqrt{48}\).
a) Côté du premier carré :
\(c = \sqrt{48} = \sqrt{16 \times 3} = 4\sqrt{3}\) cm
b) Aire du second carré : \(4 \times 48 = 192\) cm²
\(c' = \sqrt{192} = \sqrt{64 \times 3} = 8\sqrt{3}\) cm
On constate que \(c' = 2c\) : multiplier l'aire par 4 multiplie le côté par 2.
c) Périmètre \(= 4c = 4 \times 4\sqrt{3} = 16\sqrt{3}\) cm
Côté : \(4\sqrt{3}\) cm  ·  Périmètre : \(16\sqrt{3}\) cm
🔑 \(\sqrt{4a} = 2\sqrt{a}\) : multiplier une aire par 4 multiplie les longueurs par \(\sqrt{4} = 2\).

Exercice 8 / 8

Problème · valeur absolue et formules ⚠️ Difficile
✓ Vu
📏 On considère deux réels \(a\) et \(b\) avec \(a > b > 0\).
a) Quel est le signe de \(a - b\) ? Justifie.
b) En déduire la valeur de \(\sqrt{(a-b)^2}\).
c) Quel est le signe de \(b - a\) ? Que vaut alors \(\sqrt{(b-a)^2}\) ?
d) Que remarques-tu ? Interprète géométriquement ce résultat.
💡 Indices
\(\sqrt{X^2} = |X|\). Une fois que tu connais le signe de \(X\), tu peux lever la valeur absolue : si \(X \geq 0\) alors \(|X| = X\) ; si \(X < 0\) alors \(|X| = -X\).
Place \(a\) et \(b\) sur une droite des réels. La distance entre deux points \(a\) et \(b\) est la même que celle entre \(b\) et \(a\). Quel lien fais-tu avec \(|a-b|\) et \(|b-a|\) ?
a) Puisque \(a > b\), on a \(a - b > 0\).
b) On applique \(\sqrt{(a-b)^2} = |a-b|\).
Comme \(a - b > 0\), on a \(|a-b| = a - b\).
Donc \(\sqrt{(a-b)^2} = a - b\).
c) Puisque \(a > b\), on a \(b - a < 0\).
On applique \(\sqrt{(b-a)^2} = |b-a|\).
Comme \(b - a < 0\), on a \(|b-a| = -(b-a) = a - b\).
Donc \(\sqrt{(b-a)^2} = a - b\).
d) On obtient \(a - b\) dans les deux cas : \(\sqrt{(a-b)^2} = \sqrt{(b-a)^2}\).
Interprétation géométrique : \(|a - b|\) représente la distance entre les points \(a\) et \(b\) sur la droite réelle. Cette distance est la même dans les deux sens, d'où \(|a-b| = |b-a|\).
🔑 La distance entre deux réels \(a\) et \(b\) est \(|a - b| = |b - a|\). Elle est toujours positive et ne dépend pas de l'ordre.
