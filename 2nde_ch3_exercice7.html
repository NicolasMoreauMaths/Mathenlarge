📌 Deux types de démonstrations

① Prouver une égalité
On développe et réduit chaque membre séparément. Si les deux formes réduites sont identiques, l'égalité est vraie pour toute valeur. On ne passe jamais d'un membre à l'autre directement.
② Réfuter une égalité
Il suffit de trouver un seul contre-exemple : une valeur pour laquelle les deux membres donnent des résultats différents. Un seul exemple suffisant ne prouve pas que c'est vrai pour tout \(x\).
③ Règle d'or
Pour prouver que c'est vrai pour tout \(x\), il faut un calcul général (pas de valeur numérique). Pour prouver que c'est faux, un seul contre-exemple suffit.

Exercice 1 / 6

Prouver une égalité Membre par membre
✓ Vu

Prouver que chaque égalité est vraie pour tout \(x\) en développant et réduisant chaque membre séparément.

a) \((x+3)(x-3) = x^2 - 9\)
b) \(3(x+2) + 2(x-1) = 5x + 4\)
c) \((x+1)^2 - 1 = x(x+2)\)

💡 Indices

Développe et réduis le membre gauche (MG) jusqu'à sa forme la plus simple. Fais de même pour le membre droit (MD). Si MG réduit = MD réduit, c'est prouvé. Ne pas mélanger les deux membres.
Pour le membre gauche, développe \((x+1)^2\) avec l'identité ①, puis soustrais 1. Pour le membre droit, développe \(x(x+2)\) avec la distributivité simple.
Méthode : développer chaque membre séparément, les réduire, puis conclure que MG = MD.
a) \((x+3)(x-3) = x^2 - 9\)
Membre gauche
Identité ③\(x^2 - 3^2\)
\(\textcolor{#1a6fa0}{= x^2 - 9}\)
Membre droit
Déjà réduit\(\textcolor{#6b3fa0}{= x^2 - 9}\)
Conclusion : MG \(= x^2 - 9 =\) MD. L'égalité est vraie pour tout \(x\). ✓
b) \(3(x+2) + 2(x-1) = 5x + 4\)
Membre gauche
Développe\(3x + 6 + 2x - 2\)
Réduit\(\textcolor{#1a6fa0}{= 5x + 4}\)
Membre droit
Déjà réduit\(\textcolor{#6b3fa0}{= 5x + 4}\)
Conclusion : MG \(= 5x+4 =\) MD. L'égalité est vraie pour tout \(x\). ✓
c) \((x+1)^2 - 1 = x(x+2)\)
Membre gauche
Identité ①\(x^2 + 2x + 1 - 1\)
Réduit\(\textcolor{#1a6fa0}{= x^2 + 2x}\)
Membre droit
Développe\(x \times x + x \times 2\)
Réduit\(\textcolor{#6b3fa0}{= x^2 + 2x}\)
Conclusion : MG \(= x^2 + 2x =\) MD. L'égalité est vraie pour tout \(x\). ✓

Exercice 2 / 6

Prouver une égalité Calculs plus longs
✓ Vu

Prouver que chaque égalité est vraie pour tout \(x\).

a) \((x+2)^2 - (x-2)^2 = 8x\)
b) \((x+3)(x-1) - (x-2)^2 = 2x - 1\)
c) \((2x+1)^2 + (2x-1)^2 = 2(4x^2+1)\)

💡 Indices

Développe \((x+2)^2\) et \((x-2)^2\) séparément avec les identités ① et ②, puis soustrais. Quels termes vont s'annuler ?
Pour le membre droit, développe \(2(4x^2+1)\) avec la simple distributivité. Pour le membre gauche, développe les deux carrés, additionne, puis réduis. Quels termes vont s'annuler ?
a) \((x+2)^2 - (x-2)^2 = 8x\)
Membre gauche
Id. ①\((x^2 + 4x + 4)\)
Id. ②\(- (x^2 - 4x + 4)\)
Signe −\(= x^2 + 4x + 4 - x^2 + 4x - 4\)
Réduit\(\textcolor{#1a6fa0}{= 8x}\)
Membre droit
Déjà réduit\(\textcolor{#6b3fa0}{= 8x}\)
Conclusion : MG \(= 8x =\) MD. Vrai pour tout \(x\). ✓
b) \((x+3)(x-1) - (x-2)^2 = 2x - 1\)
Membre gauche
Double dist.\((x^2 - x + 3x - 3)\)
Id. ②\(- (x^2 - 4x + 4)\)
Signe −\(= x^2 + 2x - 3 - x^2 + 4x - 4\)
Réduit\(\textcolor{#1a6fa0}{= 6x - 7}\)
Membre droit
Déjà réduit\(\textcolor{#6b3fa0}{= 2x - 1}\)
Attention ! MG \(= 6x - 7 \neq 2x - 1 =\) MD. Cette égalité est fausse !

💡 Un résultat inattendu — le calcul révèle que l'énoncé était incorrect. La méthode membre par membre permet de le détecter immédiatement.

c) \((2x+1)^2 + (2x-1)^2 = 2(4x^2+1)\)
Membre gauche
Id. ①\((4x^2 + 4x + 1)\)
Id. ②\(+ (4x^2 - 4x + 1)\)
Réduit\(\textcolor{#1a6fa0}{= 8x^2 + 2}\)
Membre droit
Distribue\(2 \times 4x^2 + 2 \times 1\)
Réduit\(\textcolor{#6b3fa0}{= 8x^2 + 2}\)
Conclusion : MG \(= 8x^2 + 2 =\) MD. Vrai pour tout \(x\). ✓
⚠ Exercice b) : la méthode membre par membre a révélé que l'égalité était fausse — c'est aussi une information utile ! Le calcul ne ment pas.

Exercice 3 / 6

Contre-exemples Réfuter une affirmation
✓ Vu

Chaque affirmation est fausse. Trouver un contre-exemple qui le prouve.

a) « Pour tout \(x\) : \((x+3)^2 = x^2 + 9\). »
b) « Pour tous \(a\) et \(b\) : \((a+b)^2 = a^2 + b^2\). »
c) « Pour tout \(x\) : \(x^2 > 0\). »
d) « Pour tout \(x\) : \((x-1)(x+1) = (x-1)^2\). »

💡 Indices

Pour trouver un contre-exemple, essaie des valeurs simples : \(x = 0\), \(x = 1\), \(x = 2\). Calcule les deux membres pour chaque valeur — dès qu'ils diffèrent, tu as ton contre-exemple.
Pour c) : l'affirmation dit que \(x^2\) est strictement positif. Existe-t-il une valeur de \(x\) pour laquelle \(x^2 = 0\) ?
Rappel : un contre-exemple réfute une affirmation du type « pour tout \(x\)… ». Il suffit d'une seule valeur qui met l'affirmation en défaut.
a) « \((x+3)^2 = x^2 + 9\) »

Contre-exemple : \(x = 1\)

Membre gauche
Calcule\((1+3)^2 = 4^2 = \textcolor{#1a6fa0}{16}\)
Membre droit
Calcule\(1^2 + 9 = \textcolor{#6b3fa0}{10}\)
Conclusion : \(16 \neq 10\) pour \(x=1\). L'affirmation est fausse. ✗
b) « \((a+b)^2 = a^2 + b^2\) »

Contre-exemple : \(a = 2\), \(b = 3\)

Membre gauche
Calcule\((2+3)^2 = 25 \to \textcolor{#1a6fa0}{25}\)
Membre droit
Calcule\(4 + 9 = \textcolor{#6b3fa0}{13}\)
Conclusion : \(25 \neq 13\). L'affirmation est fausse. ✗
c) « \(x^2 > 0\) pour tout \(x\) »

Contre-exemple : \(x = 0\)

Calcule\(0^2 = 0\)
Or \(0 \not> 0\) — l'inégalité est fausse pour \(x = 0\).
Conclusion : L'affirmation est fausse — on devrait dire \(x^2 \geq 0\). ✗
d) « \((x-1)(x+1) = (x-1)^2\) »

Contre-exemple : \(x = 3\)

Membre gauche
Calcule\((3-1)(3+1) = 2 \times 4 = \textcolor{#1a6fa0}{8}\)
Membre droit
Calcule\((3-1)^2 = 2^2 = \textcolor{#6b3fa0}{4}\)
Conclusion : \(8 \neq 4\) pour \(x=3\). L'affirmation est fausse. ✗

Exercice 4 / 6

Vrai ou faux ? Prouver ou contre-exemple
✓ Vu

Pour chaque affirmation : dire si elle est vraie ou fausse, puis justifier (preuve par le calcul si vraie, contre-exemple si fausse).

a) « Pour tout \(x\) : \(2(x+3) = 2x + 6\). »
b) « Pour tout \(x\) : \((x+1)^2 = x^2 + 2x + 1\). »
c) « Pour tout \(x\) : \(x^2 + 4 = (x+2)^2\). »
d) « Pour tout \(x \geq 0\) : \(\sqrt{x^2} = x\). »

💡 Indices

Commence par tester une valeur simple comme \(x = 2\). Si les deux membres donnent la même valeur, c'est encourageant mais pas suffisant — il faut une preuve générale. Si les membres diffèrent, tu as ton contre-exemple.
L'hypothèse \(x \geq 0\) est importante. Pour \(x = 4\) : \(\sqrt{4^2} = \sqrt{16} = ?\) Développe \((x+2)^2\) pour c) et compare avec \(x^2 + 4\).
a) \(2(x+3) = 2x + 6\)

✓ VRAIE — preuve :

MG : développe\(2(x+3) = 2x + 6\)
Conclusion : MG \(= 2x+6 =\) MD. Vrai pour tout \(x\). ✓
b) \((x+1)^2 = x^2 + 2x + 1\)

✓ VRAIE — c'est exactement l'identité ① avec \(a=x\), \(b=1\) :

MG : Id. ①\(x^2 + 2 \times x \times 1 + 1^2 = x^2 + 2x + 1\)
Conclusion : MG \(= x^2+2x+1 =\) MD. Vrai pour tout \(x\). ✓
c) \(x^2 + 4 = (x+2)^2\)

❌ FAUSSE — contre-exemple : \(x = 1\)

Membre gauche
Calcule\(1^2 + 4 = \textcolor{#1a6fa0}{5}\)
Membre droit
Calcule\((1+2)^2 = 9 = \textcolor{#6b3fa0}{9}\)

En général : \((x+2)^2 = x^2 + 4x + 4 \neq x^2 + 4\).

Conclusion : \(5 \neq 9\) pour \(x=1\). Fausse. ✗
d) \(\sqrt{x^2} = x\) pour tout \(x \geq 0\)

✓ VRAIE pour \(x \geq 0\) — preuve : par définition, \(\sqrt{x^2}\) est le nombre positif dont le carré est \(x^2\), c'est-à-dire \(x\) lui-même puisque \(x \geq 0\).

Conclusion : Vrai pour tout \(x \geq 0\). (Attention : sans la condition \(x \geq 0\), ce serait faux — ex. \(x=-3\) : \(\sqrt{(-3)^2} = 3 \neq -3\).) ✓

Exercice 5 / 6

Démonstration complète Propriétés numériques
✓ Vu

Démontrer chaque propriété à l'aide du calcul littéral. Rédiger la démonstration complète.

a) La somme de deux entiers consécutifs est impaire. (Les deux entiers consécutifs sont \(n\) et \(n+1\).)
b) Le produit de deux entiers consécutifs est toujours pair. (Les deux entiers consécutifs sont \(n\) et \(n+1\).)
c) Le carré d'un entier impair est toujours impair. (Indice : tout entier impair s'écrit \(2k+1\) avec \(k\) entier.)

💡 Indices

Développe \((2k+1)^2\) avec l'identité ①. Le résultat est-il de la forme \(2m + 1\) pour un certain entier \(m\) ? C'est la définition d'un nombre impair.
Développe \(n(n+1)\). Un nombre est pair s'il s'écrit \(2m\) pour un certain entier \(m\). Peut-on mettre en facteur commun pour faire apparaître un \(2\) ?
Méthode : on exprime la situation avec des lettres, on développe, puis on montre que le résultat a la forme voulue (pair = \(2 \times \text{entier}\), impair = \(2 \times \text{entier} + 1\)).
a) Somme de deux entiers consécutifs

Soient \(n\) et \(n+1\) deux entiers consécutifs. Leur somme vaut :

Calcule\(n + (n+1) = 2n + 1\)
Conclusion : \(2n+1\) est de la forme \(2 \times \text{entier} + 1\) : c'est un impair. La somme de deux entiers consécutifs est impaire. ✓
b) Produit de deux entiers consécutifs

Soient \(n\) et \(n+1\) deux entiers consécutifs. Leur produit vaut :

Développe\(n(n+1) = n^2 + n\)
Factorise\(= n(n+1)\)
Parmi \(n\) et \(n+1\)l'un des deux est forcément pair (deux consécutifs ont des parités différentes)
Conclusion : Le produit de deux entiers consécutifs est toujours pair (pair × n'importe quoi = pair). ✓
c) Carré d'un entier impair

Soit \(k\) un entier. Tout entier impair s'écrit \(2k+1\). Calculons son carré :

Id. ①\((2k+1)^2 = 4k^2 + 4k + 1\)
Factorise\(= 2(2k^2 + 2k) + 1\)
\(2k^2 + 2k\) est un entier, donc \(2(2k^2+2k)+1\) est de la forme \(2 \times \text{entier} + 1\)
Conclusion : \((2k+1)^2\) est un entier impair. ✓

Exercice 6 / 6

Synthèse Démontrer Contre-exemple ⭐ Difficile
✓ Vu

Exercice difficile — il mobilise toutes les compétences du chapitre. Prends le temps de bien lire chaque question avant de répondre.

Un élève prétend avoir trouvé une formule magique pour calculer des carrés rapidement :

« Pour tout entier \(n\), on a \((n+1)^2 = n^2 + 2n + 1\). Donc pour calculer \((n+1)^2\), il suffit de connaître \(n^2\) et d'ajouter \(2n+1\). »
1) Prouver que la formule \((n+1)^2 = n^2 + 2n + 1\) est bien vraie pour tout \(n\).
2) Vérifier la formule pour \(n = 7\) : utiliser la formule pour calculer \(8^2\) à partir de \(7^2 = 49\).
3) Un autre élève affirme qu'on peut aussi écrire \((n+1)^2 = n^2 + (2n+1)\) et que la valeur \(2n+1\) est toujours impaire. Montrer que \(2n+1\) est bien impair pour tout entier \(n\).
4) En déduire une propriété sur la différence entre deux carrés d'entiers consécutifs.

💡 Indices

Développe \((n+1)^2\) avec l'identité ① et compare avec le membre droit. C'est une démonstration très courte.
La formule dit que \((n+1)^2 - n^2 = 2n+1\). Que vient-on de prouver sur \(2n+1\) à la question 3) ?
1) Preuve de \((n+1)^2 = n^2 + 2n + 1\)
Membre gauche
Id. ①\(n^2 + 2 \times n \times 1 + 1^2\)
Réduit\(\textcolor{#1a6fa0}{= n^2 + 2n + 1}\)
Membre droit
Déjà réduit\(\textcolor{#6b3fa0}{= n^2 + 2n + 1}\)
Conclusion : MG = MD. La formule est vraie pour tout \(n\). ✓
2) Vérification pour \(n = 7\)
Formule\(8^2 = 7^2 + 2 \times 7 + 1 = 49 + 14 + 1\)
\(8^2 = 64\) ✓
3) \(2n+1\) est impair
Forme\(2n + 1 = 2 \times n + 1\)
C'est de la forme \(2m + 1\) avec \(m = n\) entier : c'est un nombre impair.
Conclusion : \(2n+1\) est impair pour tout entier \(n\). ✓
4) Propriété déduite

D'après la formule prouvée en Q1 : \((n+1)^2 - n^2 = 2n+1\).

D'après Q3 : \(2n+1\) est impair.

La différence entre deux carrés d'entiers consécutifs est toujours un nombre impair. ✓
