for — La boucle et range(n)
›
Objectif n°1

Comprendre comment répéter des instructions un nombre fixe de fois avec for et range().

Une boucle for permet de répéter un bloc d'instructions. range(n) génère les entiers de 0 à n−1.

Syntaxe :
for i in range(n) :
    # instructions répétées n fois

⚠ Le bloc à répéter doit être indenté (décalé de 4 espaces ou une tabulation Tab). C'est l'indentation qui indique à Python ce qui est "dans" la boucle.
ExpressionValeurs produitesNombre de tours
range(5)0, 1, 2, 3, 45 tours
range(3)0, 1, 23 tours
range(1)01 tour
range(0)(rien)0 tour

def — Créer une fonction
›
Objectif n°3

Comprendre ce qu'est une fonction, comment la définir avec def et comment l'appeler.

Une fonction est un bloc d'instructions auquel on donne un nom, pour pouvoir le réutiliser facilement. Plutôt que de réécrire le même code plusieurs fois, on l'écrit une seule fois dans une fonction et on l'appelle autant de fois qu'on veut.

Syntaxe :
def nom_de_la_fonction(parametre1, parametre2) :
    # instructions de la fonction

Puis pour l'utiliser :
nom_de_la_fonction(valeur1, valeur2)
⚠ Définir ≠ Appeler ! Écrire def ma_fonction(): crée la fonction mais ne l'exécute pas. Pour l'exécuter, il faut l'appeler : ma_fonction().

return — Renvoyer un résultat
›
Objectif n°4

Apprendre à renvoyer une valeur depuis une fonction avec return, pour pouvoir réutiliser le résultat dans la suite du programme.

Jusqu'ici nos fonctions affichaient des choses mais ne renvoyaient rien. Avec return, une fonction peut renvoyer une valeur qu'on peut stocker dans une variable ou réutiliser dans un calcul.

Sans returnAvec return
def double(x):
    print(x * 2)

double(5)  # affiche 10
y = double(5) # y vaut None !		 def double(x):
    return x * 2

y = double(5) # y vaut 10
print(y)      # affiche 10
Règle : return arrête immédiatement la fonction et renvoie la valeur indiquée. Tout code écrit après un return dans la même fonction ne sera jamais exécuté.
