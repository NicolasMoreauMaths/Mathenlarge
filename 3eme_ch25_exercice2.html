Exercice 1 — Développer

✓ Vu

Développer et réduire :

a) $A = 5(2x - 3)$
b) $B = -4(3x + 1)$
c) $C = 2x(x - 5)$
🔎 On multiplie le facteur devant la parenthèse par chaque terme à l'intérieur : $\textcolor{#1a6fa0}{k}(\textcolor{#c0392b}{a} + \textcolor{#6b3fa0}{b}) = \textcolor{#1a6fa0}{k}\textcolor{#c0392b}{a} + \textcolor{#1a6fa0}{k}\textcolor{#6b3fa0}{b}$.
facteur $k$ 1er terme 2e terme

a) $A = 5(2x - 3)$

$A = \textcolor{#1a6fa0}{5} \times \textcolor{#c0392b}{2x} - \textcolor{#1a6fa0}{5} \times \textcolor{#6b3fa0}{3} = \boxed{10x - 15}$

b) $B = -4(3x + 1)$

$B = \textcolor{#1a6fa0}{(-4)} \times \textcolor{#c0392b}{3x} + \textcolor{#1a6fa0}{(-4)} \times \textcolor{#6b3fa0}{1} = \boxed{-12x - 4}$

c) $C = 2x(x - 5)$

$C = \textcolor{#1a6fa0}{2x} \times \textcolor{#c0392b}{x} - \textcolor{#1a6fa0}{2x} \times \textcolor{#6b3fa0}{5} = \boxed{2x^2 - 10x}$

Exercice 2 — Supprimer les parenthèses

✓ Vu

Supprimer les parenthèses puis réduire :

a) $A = 7x + (3x - 5)$
b) $B = 7x - (3x - 5)$
🔎 Signe $\textcolor{#1b7a40}{+}$ devant : on recopie tel quel. Signe $\textcolor{#c0392b}{-}$ devant : on change tous les signes à l'intérieur.

a) $A = 7x \textcolor{#1b7a40}{+} (3x - 5)$

Signe $\textcolor{#1b7a40}{+}$ → on ne change rien :

$A = 7x \textcolor{#1b7a40}{+ 3x - 5} = \boxed{10x - 5}$

b) $B = 7x \textcolor{#c0392b}{-} (3x - 5)$

Signe $\textcolor{#c0392b}{-}$ → on change tous les signes :

$B = 7x \textcolor{#c0392b}{- 3x + 5} = \boxed{4x + 5}$

$+3x$ devient $\textcolor{#c0392b}{-3x}$ et $-5$ devient $\textcolor{#c0392b}{+5}$.

Exercice 3 — Factoriser

✓ Vu

Factoriser les expressions :

a) $A = 15x - 10$
b) $B = 6x^2 + 9x$
c) $C = 8x^2 - 12x$
🔎 Cherche le plus grand nombre qui divise les deux coefficients. Regarde aussi si $x$ apparaît dans tous les termes : si oui, il fait partie du facteur commun.
facteur commun ce qui reste (1er) ce qui reste (2e)

a) $A = 15x - 10$

$A = \textcolor{#1a6fa0}{5} \times \textcolor{#c0392b}{3x} - \textcolor{#1a6fa0}{5} \times \textcolor{#6b3fa0}{2} = \boxed{\textcolor{#1a6fa0}{5}(\textcolor{#c0392b}{3x} - \textcolor{#6b3fa0}{2})}$

b) $B = 6x^2 + 9x$

$6x^2 = \textcolor{#1a6fa0}{3x} \times \textcolor{#c0392b}{2x}$ et $9x = \textcolor{#1a6fa0}{3x} \times \textcolor{#6b3fa0}{3}$. Facteur commun : $\textcolor{#1a6fa0}{3x}$.

$B = \textcolor{#1a6fa0}{3x} \times \textcolor{#c0392b}{2x} + \textcolor{#1a6fa0}{3x} \times \textcolor{#6b3fa0}{3} = \boxed{\textcolor{#1a6fa0}{3x}(\textcolor{#c0392b}{2x} + \textcolor{#6b3fa0}{3})}$

c) $C = 8x^2 - 12x$

$8x^2 = \textcolor{#1a6fa0}{4x} \times \textcolor{#c0392b}{2x}$ et $12x = \textcolor{#1a6fa0}{4x} \times \textcolor{#6b3fa0}{3}$. Facteur commun : $\textcolor{#1a6fa0}{4x}$.

$C = \textcolor{#1a6fa0}{4x} \times \textcolor{#c0392b}{2x} - \textcolor{#1a6fa0}{4x} \times \textcolor{#6b3fa0}{3} = \boxed{\textcolor{#1a6fa0}{4x}(\textcolor{#c0392b}{2x} - \textcolor{#6b3fa0}{3})}$

Exercice 4 — Développer et réduire

✓ Vu

Développer, puis réduire les expressions :

a) $E = 3(x + 2) + 5(x - 1)$
b) $F = 4(2x + 3) - 2(x - 4)$
c) $G = x(x + 6) - (2x^2 - 3x + 1)$
🔎 Développe chaque produit séparément, puis regroupe et réduis les termes de même nature. Attention au signe $-$ devant une parenthèse !

a) $E = 3(x + 2) + 5(x - 1)$

$E = \textcolor{#1a6fa0}{3} \times \textcolor{#c0392b}{x} + \textcolor{#1a6fa0}{3} \times \textcolor{#6b3fa0}{2} + \textcolor{#b85c0b}{5} \times \textcolor{#c0392b}{x} - \textcolor{#b85c0b}{5} \times \textcolor{#6b3fa0}{1}$
$E = 3x + 6 + 5x - 5$
$E = \textcolor{#1a6fa0}{3x + 5x} + \textcolor{#c0392b}{6 - 5} = \boxed{8x + 1}$

b) $F = 4(2x + 3) - 2(x - 4)$

$F = \textcolor{#1a6fa0}{4} \times \textcolor{#c0392b}{2x} + \textcolor{#1a6fa0}{4} \times \textcolor{#6b3fa0}{3} - \textcolor{#b85c0b}{2} \times \textcolor{#c0392b}{x} + \textcolor{#b85c0b}{2} \times \textcolor{#6b3fa0}{4}$

⚠️ $-2(x - 4) = -2x \textcolor{#c0392b}{+} 8$ (le $-$ change le signe du $-4$)

$F = 8x + 12 - 2x + 8$
$F = \textcolor{#1a6fa0}{8x - 2x} + \textcolor{#c0392b}{12 + 8} = \boxed{6x + 20}$

c) $G = x(x + 6) - (2x^2 - 3x + 1)$

On développe $x(x+6)$, puis on supprime la parenthèse (signe $\textcolor{#c0392b}{-}$) :

$G = \textcolor{#1a6fa0}{x} \times \textcolor{#c0392b}{x} + \textcolor{#1a6fa0}{x} \times \textcolor{#6b3fa0}{6} \textcolor{#c0392b}{- 2x^2 + 3x - 1}$
$G = x^2 + 6x - 2x^2 + 3x - 1$
$x^2$ $x$ cst
$G = \textcolor{#6b3fa0}{(1 - 2)x^2} + \textcolor{#1a6fa0}{(6 + 3)x} \textcolor{#c0392b}{- 1} = \boxed{-x^2 + 9x - 1}$

Exercice 5 — Prouver une égalité

✓ Vu

Prouver que pour tout nombre $x$ :

$$3(x + 4) - (x - 2) = 2(x + 7)$$
🔎 Développe et réduis chaque membre séparément. Si tu obtiens la même expression des deux côtés, l'égalité est prouvée.

Membre de gauche :

$3(x + 4) - (x - 2)$
$= \textcolor{#1a6fa0}{3} \times \textcolor{#c0392b}{x} + \textcolor{#1a6fa0}{3} \times \textcolor{#6b3fa0}{4} \textcolor{#c0392b}{- x + 2}$
$= 3x + 12 - x + 2$
$= \textcolor{#1b7a40}{2x + 14}$

Membre de droite :

$2(x + 7)$
$= \textcolor{#1a6fa0}{2} \times \textcolor{#c0392b}{x} + \textcolor{#1a6fa0}{2} \times \textcolor{#6b3fa0}{7}$
$= \textcolor{#1b7a40}{2x + 14}$
Les deux membres sont égaux à $\textcolor{#1b7a40}{2x + 14}$. L'égalité est donc vraie pour tout $x$.

Exercice 6 — Contre-exemples

✓ Vu

Pour chaque affirmation, trouver un contre-exemple pour prouver qu'elle est fausse.

Affirmation 1 : « Pour tout nombre $x$ : $2(x + 3) = 2x + 3$. »

Affirmation 2 : « Pour tout nombre $x$ : $(2x)^2 = 2x^2$. »

Affirmation 3 : « Pour tout nombre $x$ : $3x + 4x^2 = 7x^3$. »

🔎 Choisis une valeur simple de $x$ (par exemple $x = 1$ ou $x = 2$), calcule chaque côté et compare. Si les résultats sont différents, c'est un contre-exemple.

Affirmation 1 : FAUX ❌

Avec $\textcolor{#1a6fa0}{x = 1}$ :

$2(\textcolor{#1a6fa0}{1} + 3) = 2 \times 4 = \textcolor{#6b3fa0}{8}$
$2 \times \textcolor{#1a6fa0}{1} + 3 = 2 + 3 = \textcolor{#6b3fa0}{5}$
$8 \neq 5$. En réalité : $2(x + 3) = 2x + 6$.

Affirmation 2 : FAUX ❌

Avec $\textcolor{#1a6fa0}{x = 3}$ :

$(2 \times \textcolor{#1a6fa0}{3})^2 = 6^2 = \textcolor{#6b3fa0}{36}$
$2 \times \textcolor{#1a6fa0}{3}^2 = 2 \times 9 = \textcolor{#6b3fa0}{18}$
$36 \neq 18$. En réalité : $(2x)^2 = 4x^2$.

Affirmation 3 : FAUX ❌

Avec $\textcolor{#1a6fa0}{x = 2}$ :

$3 \times \textcolor{#1a6fa0}{2} + 4 \times \textcolor{#1a6fa0}{2}^2 = 6 + 16 = \textcolor{#6b3fa0}{22}$
$7 \times \textcolor{#1a6fa0}{2}^3 = 7 \times 8 = \textcolor{#6b3fa0}{56}$
$22 \neq 56$. $3x$ et $4x^2$ ne sont pas de même nature : on ne peut pas les additionner.
