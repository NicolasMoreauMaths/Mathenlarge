bool — Les valeurs logiques
›
Objectif n°3

Comprendre le type bool et les opérateurs de comparaison qui permettent de poser des questions à Python.

Un booléen (bool) ne peut prendre que deux valeurs : True (vrai) ou False (faux). Python les produit automatiquement lors d'une comparaison.

⚠ Attention à la majuscule ! C'est True et False avec une majuscule. true ou false provoquent une erreur.
OpérateurSignificationComment le taperExempleRésultat
==Égal à= deux fois5 == 5True
!=Différent de! puis =5 != 3True
<Inférieur strict< (touche à gauche de >)3 < 5True
>Supérieur strict> (Maj + <)3 > 5False
<=Inférieur ou égal< puis =5 <= 5True
>=Supérieur ou égal> puis =4 >= 7False
⚠ Ne pas confondre = et == !
= (un seul symbole) → affecte une valeur à une variable : a = 5
== (deux symboles collés) → compare et renvoie True ou False : a == 5
C'est l'une des erreurs les plus fréquentes en Python !
