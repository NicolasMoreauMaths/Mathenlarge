Le Domaine de Définition

IV. Le domaine de définition
📘 Définition

Le domaine de définition \(D_f\) d'une fonction \(f\) est l'ensemble de toutes les valeurs de départ autorisées, c'est-à-dire celles pour lesquelles le calcul de \(f(x)\) est possible.

🤔 Pourquoi certaines valeurs seraient-elles interdites ?

La plupart du temps, toutes les valeurs de départ conviennent. Mais deux situations posent problème :

  • La division par zéro est impossible. Si \(f(x) = \dfrac{1}{x}\), la valeur \(x = 0\) est interdite car on ne peut pas diviser par \(0\).
  • La racine carrée d'un nombre négatif est impossible. Si \(f(x) = \sqrt{x}\), les valeurs \(x < 0\) sont interdites.
1
Fonction sans restriction : \(f(x) = 2x + 1\)
On observe : on peut remplacer \(x\) par n'importe quel nombre — positif, négatif, décimal… Le calcul \(2x + 1\) donne toujours un résultat.
✅ Toutes les valeurs de départ conviennent : \(D_f = \mathbb{R}\)
2
Division par zéro : \(g(x) = \dfrac{5}{x - 3}\)
On cherche : quelle valeur de départ rend le dénominateur nul ?
\(x - 3 = 0 \implies x = 3\)
La valeur \(x = 3\) est interdite (division par zéro). Toutes les autres valeurs conviennent.
✅ \(D_g = \mathopen]-\infty\,;\,3\mathclose[\;\cup\;\mathopen]3\,;\,+\infty\mathclose[\)

Lecture : toutes les valeurs réelles sauf \(3\) — c'est-à-dire les valeurs inférieures à \(3\) et les valeurs supérieures à \(3\).

💡 Notation bonus — On voit parfois l'écriture \(\mathbb{R} \setminus \{3\}\), qui se lit « \(\mathbb{R}\) privé de \(\{3\}\) ». C'est la même chose, mais la notation avec la réunion d'intervalles ci-dessus est celle que l'on privilégie.
3
Racine carrée : \(h(x) = \sqrt{x - 1}\)
On cherche : pour quelles valeurs de départ l'expression sous la racine est-elle positive ou nulle ?
\(x - 1 \geq 0\)
\(x \geq 1\)
Toute valeur \(x < 1\) (comme \(x = 0\) ou \(x = -5\)) est interdite.
✅ \(D_h = \mathopen[1\,;\,+\infty\mathclose[\)

Lecture : toutes les valeurs de départ supérieures ou égales à \(1\).

🧩 Exercice

Détermine le domaine de définition de \(k(x) = \dfrac{3}{x + 2}\). Quelle valeur de départ est interdite ? Pourquoi ?

On cherche : quand le dénominateur est-il nul ?
\(x + 2 = 0 \implies x = -2\)

La valeur \(x = -2\) est interdite (division par zéro).

\(D_k = \mathopen]-\infty\,;\,-2\mathclose[\;\cup\;\mathopen]-2\,;\,+\infty\mathclose[\)
