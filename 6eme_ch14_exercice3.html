Ordre croissant Ordre décroissant

📌 Ce qu'il faut savoir

Ranger une liste
On compare les nombres deux à deux (méthode de la Fiche 2), en commençant par les parties entières pour former des groupes. On peut s'aider de la demi-droite : un nombre plus à droite est toujours plus grand.
Croissant vs décroissant
Ordre croissant : du plus petit au plus grand (→ vers la droite sur la demi-droite).
Ordre décroissant : du plus grand au plus petit (← vers la gauche).

Exercice 1 / 3

Ranger Ordre croissant
✓ Vu

Range chaque liste dans l'ordre croissant (du plus petit au plus grand).

a) 3,2  ·  1,7  ·  3,8  ·  2,5
b) 5,04  ·  5,4  ·  5,40  ·  5,004
c) 0,9  ·  0,09  ·  0,99  ·  0,909

💡 Indice

Pour b) : commence par la partie entière (toutes à 5), puis compare les dixièmes. Pour c) : toutes ont partie entière 0 — compare les dixièmes d'abord : 9, 0, 9, 9 → celui avec 0 au rang des dixièmes est le plus petit.
a) 3,2 · 1,7 · 3,8 · 2,5

Parties entières : 1, 2, 3, 3. On regroupe : 1,7 < 2,5, puis entre 3,2 et 3,8 : dixièmes 2 < 8.

1,7 < 2,5 < 3,2 < 3,8
b) 5,04 · 5,4 · 5,40 · 5,004

Même partie entière (5). Dixièmes : 0, 4, 4, 0. On compare centièmes pour les paires à même dixième : 5,04 vs 5,004 → centièmes : 4 > 0 → 5,004 < 5,04. Et 5,4 = 5,40.

5,004 < 5,04 < 5,4 = 5,40

💡 5,4 et 5,40 sont égaux — un zéro de fin ne change pas la valeur.

c) 0,9 · 0,09 · 0,99 · 0,909

Parties entières = 0. Dixièmes : 9, 0, 9, 9. Seul 0,09 a 0 au rang des dixièmes → le plus petit. Pour les trois autres, centièmes : 0, 9, 0. Donc 0,9 (= 0,900) < 0,909 < 0,99.

0,09 < 0,9 < 0,909 < 0,99

Exercice 2 / 3

Ranger Ordre décroissant
✓ Vu

Range dans l'ordre décroissant (du plus grand au plus petit).

a) 7,3  ·  7,03  ·  7,33  ·  7,303
b) 12,1  ·  9,98  ·  11,5  ·  10

💡 Indice

L'ordre décroissant, c'est l'inverse du croissant. Tu peux d'abord ranger dans l'ordre croissant, puis écrire ta liste à l'envers.
a) 7,3 · 7,03 · 7,33 · 7,303

Même entière (7). Dixièmes : 3, 0, 3, 3. Le seul à 0 : 7,03 le plus petit. Pour les trois autres : centièmes : 0, 3, 0 → 7,3 = 7,300 et 7,303 → millièmes : 0 < 3 → 7,3 < 7,303. Et 7,33 > 7,303 (centièmes : 3 > 0).

Croissant : 7,03 < 7,3 < 7,303 < 7,33

Décroissant : 7,33 > 7,303 > 7,3 > 7,03
b) 12,1 · 9,98 · 11,5 · 10

Parties entières : 12, 9, 11, 10. Toutes différentes → on range les entiers : 9 < 10 < 11 < 12.

Croissant : 9,98 < 10 < 11,5 < 12,1

Décroissant : 12,1 > 11,5 > 10 > 9,98

Exercice 3 / 3

Ranger Lien avec la demi-droite
✓ Vu

On reprend tous les points des fiches précédentes :

A (0,7) · B (1,3) · C (2,5) · D (3,8) · E (4,4) issus de la Fiche 1,
et on ajoute P (1,03) et Q (3,74).

a) Range les abscisses de A, B, C, D, E, P et Q dans l'ordre croissant.
b) Sur ton cahier, trace une demi-droite graduée de 0 à 5 : utilise 2 cm pour représenter une unité (donc 2 mm entre chaque dixième). Gradue-la à partir de 0 en plaçant les entiers 1, 2, 3, 4, 5, puis les dixièmes intermédiaires. Place ensuite les points A, B, C, D et P. Vérifie que P est entre A et B.
c) Quel est le plus grand de ces sept nombres ? Le plus petit ?

💡 Indice

Regroupe d'abord par partie entière : 0 → A(0,7) ; 1 → B(1,3), P(1,03) ; 2 → C(2,5) ; 3 → D(3,8), Q(3,74) ; 4 → E(4,4). Puis compare à l'intérieur de chaque groupe.
a) Ordre croissant

Groupes par entière : {A:0,7} · {P:1,03, B:1,3} · {C:2,5} · {Q:3,74, D:3,8} · {E:4,4}.
Dans le groupe 1 : 1,03 < 1,3 (dixièmes 0 < 3).
Dans le groupe 3 : 3,74 < 3,8 (dixièmes 7 = 7, centièmes 4 < — non : dixièmes 7 et 8 → 7 < 8 donc 3,74 < 3,8).

0,7 < 1,03 < 1,3 < 2,5 < 3,74 < 3,8 < 4,4

soit A < P < B < C < Q < D < E

b) Placement sur la demi-droite

A en 0,7 ; P en 1,03 ; B en 1,3 ; C en 2,5 ; D en 3,8. En lisant de gauche à droite : A puis P puis B — P est bien entre A et B. ✓

On lit bien : A (0,7) · P (1,03) · B (1,3) — P est entre A et B. ✓

c) Plus grand / plus petit
Plus grand : E (abscisse 4,4) · Plus petit : A (abscisse 0,7)
