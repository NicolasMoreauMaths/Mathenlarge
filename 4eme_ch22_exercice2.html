Qu'est-ce qu'une variable ?
🟠 Je découvre
📦 La définition à retenir
Une variable est une mémoire qui sert à stocker une ou plusieurs informations.

On peut l'imaginer comme une boîte avec une étiquette : l'étiquette, c'est le nom de la variable ; ce qu'il y a dans la boîte, c'est sa valeur.

  • Dans Scratch, on crée une variable dans la catégorie Variables avec le bouton « Créer une variable », puis on lui donne un nom.
  • Un programme peut utiliser plusieurs variables pour garder en mémoire plusieurs informations en même temps.
  • « mettre … à … » range une nouvelle valeur dans la boîte : l'ancienne valeur est effacée.
  • « ajouter … à … » modifie la valeur en partant de l'ancienne.
  • Le bloc rond orange nombre permet de lire la valeur rangée pour l'utiliser dans un calcul.

Vers le calcul littéral
🟣 Je généralise
✏️
Une variable, comme une lettreEn maths, quand on ne connaît pas le nombre choisi, on l'appelle \(x\). C'est exactement le rôle d'une variable : elle représente n'importe quel nombre.
🔤 Astuce : dans un simulateur débloqué, clique sur le bouton avec x : la variable contiendra alors une expression littérale au lieu d'un nombre !
✏️ Exercice 8 — Quelle expression ?

On appelle \(x\) le nombre choisi. Quelle expression donne le nombre dit par le lutin ?

A\((x+5)\times 2-10\)
B\(x+5\times 2-10\)
C\(x\times 2+5-10\)
❌ Ce n'est pas celle-là : relis l'ordre des blocs et réessaie.
✅ Réponse A. On ajoute 5 d'abord, puis on multiplie tout par 2 : il faut des parenthèses. Et surprise : $$(x+5)\times 2-10 = 2x+10-10 = 2x$$ Ce programme donne toujours le double du nombre choisi ! Vérifie-le avec le simulateur, qui vient de se débloquer : clique sur avec x.
⚖️ Exercice 9 — Deux programmes jumeaux ?

Teste ces deux programmes avec plusieurs nombres (change le « nombre choisi » puis clique sur Exécuter). Donnent-ils toujours le même résultat ?

ANon, jamais le même résultat.
BSeulement pour certains nombres.
COui, toujours : \(3x+6=3(x+2)\).
❌ Teste avec d'autres nombres (et même avec avec x) puis réessaie.
✅ Réponse C. Programme A : \(x\times 3+6=3x+6\). Programme B : on développe \((x+2)\times 3=3x+6\). Les deux expressions sont égales, donc les programmes donnent toujours le même résultat. Tester quelques nombres donne une idée ; le calcul littéral le prouve.
