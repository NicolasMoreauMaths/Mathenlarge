🔍Comprendre les signes dans les calculs

Dans un calcul comme 4 − 8, on peut voir directement :
• +4 : un nombre positif (jetons verts)
• −8 : un nombre négatif (jetons rouges)
Le signe "−" fait partie du nombre −8 !

📘Exemple : 4 − 8

On voit directement les deux nombres avec leurs signes

🎨Avec plusieurs nombres

Quand tu vois +2 −4 +8 −7 +5, regroupe :
• Les positifs : +2 +8 +5 = +15
• Les négatifs : −4 −7 = −11
Puis calcule : +15 −11 = +4
