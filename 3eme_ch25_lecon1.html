Calcul littéral

Simplifier · Réduire · Développer · Factoriser · Démontrer

🎯 Ce que tu dois savoir faire
  • Calculer la valeur d'une expression littérale pour des valeurs données.
  • Simplifier et réduire une expression littérale.
  • Développer en utilisant la simple distributivité.
  • Supprimer des parenthèses précédées d'un signe $+$ ou $-$.
  • Factoriser une somme ou une différence.
  • Utiliser le calcul littéral pour démontrer une propriété.
🔮 Rappel

On a : $x^2 = x \times x$   et   $x^3 = x \times x \times x$

I — Utiliser une expression littérale
📘 Définition

Calculer la valeur d'une expression littérale, c'est attribuer un nombre à chaque lettre de l'expression afin d'effectuer le calcul.

🔍 Exemple

Calculer $A = 2x^3 - y^2 + 8(x - 1)$ lorsque $\textcolor{#1a6fa0}{x = -2}$ et $\textcolor{#c0392b}{y = -5}$.

on remplace $x$ on remplace $y$ priorité : puissances priorité : × puis +/−

$A = 2x^3 - y^2 + 8(x - 1)$

$A = 2 \times \textcolor{#1a6fa0}{(-2)}^3 - \textcolor{#c0392b}{(-5)}^2 + 8 \times (\textcolor{#1a6fa0}{(-2)} - 1)$

$A = 2 \times \textcolor{#6b3fa0}{(-8)} - \textcolor{#6b3fa0}{25} + 8 \times \textcolor{#6b3fa0}{(-3)}$

$A = \textcolor{#b85c0b}{(-16)} - \textcolor{#b85c0b}{25} + \textcolor{#b85c0b}{(-24)}$

$A = -16 - 25 - 24$

$A = \boxed{-65}$

II — Simplifier et réduire
1. Simplifier
📘 Convention

Dans une expression littérale, on peut supprimer le signe $\times$ lorsqu'il est placé devant une lettre ou une parenthèse pour simplifier une expression.

📗 Propriété

Pour simplifier un produit de plusieurs facteurs, on peut modifier l'ordre de ses facteurs.

✏️ Application

Simplifier les expressions suivantes :

1) $2 \times b$
2) $a \times b$
3) $1 \times x$
4) $4 \times (7a + 3)$
5) $2x \times 3x$
6) $x \times x$
7) $x \times x \times x$
8) $3x \times 2x \times 2x$
9) $2x \times 3y \times 2x$
10) $4 \times x \times 2 + y \times 3 \times y \times 2 \times y$
1) $2 \times b = \textcolor{#1b7a40}{2b}$
2) $a \times b = \textcolor{#1b7a40}{ab}$
3) $1 \times x = \textcolor{#1b7a40}{x}$
4) $4 \times (7a + 3) = \textcolor{#1b7a40}{4(7a + 3)}$
5) $\textcolor{#1a6fa0}{2} x \times \textcolor{#c0392b}{3} x = \textcolor{#1a6fa0}{2} \times \textcolor{#c0392b}{3} \times x \times x = \textcolor{#1b7a40}{6x^2}$
6) $x \times x = \textcolor{#1b7a40}{x^2}$
7) $x \times x \times x = \textcolor{#1b7a40}{x^3}$
8) $\textcolor{#1a6fa0}{3}x \times \textcolor{#c0392b}{2}x \times \textcolor{#6b3fa0}{2}x = \textcolor{#1a6fa0}{3} \times \textcolor{#c0392b}{2} \times \textcolor{#6b3fa0}{2} \times x \times x \times x = \textcolor{#1b7a40}{12x^3}$
9) $\textcolor{#1a6fa0}{2}x \times \textcolor{#c0392b}{3}y \times \textcolor{#6b3fa0}{2}x = \textcolor{#1a6fa0}{2} \times \textcolor{#c0392b}{3} \times \textcolor{#6b3fa0}{2} \times x \times x \times y = \textcolor{#1b7a40}{12x^2y}$
10) $\textcolor{#1a6fa0}{4} \times x \times \textcolor{#1a6fa0}{2} + y \times \textcolor{#c0392b}{3} \times y \times \textcolor{#c0392b}{2} \times y = \textcolor{#1b7a40}{8x + 6y^3}$
2. Réduire
📗 Propriété

$a$, $b$, $x$ désignent trois nombres.

Pour réduire une somme : $\textcolor{#1a6fa0}{a}x + \textcolor{#c0392b}{b}x = (\textcolor{#1a6fa0}{a} + \textcolor{#c0392b}{b})x$
Pour réduire une différence : $\textcolor{#1a6fa0}{a}x - \textcolor{#c0392b}{b}x = (\textcolor{#1a6fa0}{a} - \textcolor{#c0392b}{b})x$
✏️ Application

Réduire, si possible, les expressions suivantes :

1) $2x + 3x$
2) $5x - 3x$
3) $2x + 2y$
4) $3x + 10$
5) $x + x$
6) $3x + 2y + x$
7) $4x + 12 - 3x + 8$
1) $\textcolor{#1a6fa0}{2}x + \textcolor{#1a6fa0}{3}x = \textcolor{#1b7a40}{5x}$
2) $\textcolor{#1a6fa0}{5}x - \textcolor{#1a6fa0}{3}x = \textcolor{#1b7a40}{2x}$
3) $2\textcolor{#1a6fa0}{x} + 2\textcolor{#c0392b}{y}$ → non réductible (pas la même lettre)
4) $3\textcolor{#1a6fa0}{x} + \textcolor{#c0392b}{10}$ → non réductible (un terme avec $x$, l'autre sans)
5) $\textcolor{#1a6fa0}{1}x + \textcolor{#1a6fa0}{1}x = \textcolor{#1b7a40}{2x}$
6) $\textcolor{#1a6fa0}{3x} + 2y + \textcolor{#1a6fa0}{x} = \textcolor{#1b7a40}{4x + 2y}$
7) $\textcolor{#1a6fa0}{4x} + \textcolor{#c0392b}{12} \textcolor{#1a6fa0}{- 3x} + \textcolor{#c0392b}{8} = \textcolor{#1b7a40}{x + 20}$
III — Développer
1. Simple distributivité
📘 Définition

Développer, c'est transformer un produit en somme ou en différence.

📗 Propriété

$k$, $a$ et $b$ désignent des nombres.

$\textcolor{#1a6fa0}{k}(\textcolor{#c0392b}{a} + \textcolor{#6b3fa0}{b}) = \textcolor{#1a6fa0}{k}\textcolor{#c0392b}{a} + \textcolor{#1a6fa0}{k}\textcolor{#6b3fa0}{b}$   et   $\textcolor{#1a6fa0}{k}(\textcolor{#c0392b}{a} - \textcolor{#6b3fa0}{b}) = \textcolor{#1a6fa0}{k}\textcolor{#c0392b}{a} - \textcolor{#1a6fa0}{k}\textcolor{#6b3fa0}{b}$
🔍 Exemple 1

Développer : $A = \textcolor{#1a6fa0}{7}(\textcolor{#c0392b}{4} + \textcolor{#6b3fa0}{x})$

facteur $k$ premier terme deuxième terme

$A = \textcolor{#1a6fa0}{7}(\textcolor{#c0392b}{4} + \textcolor{#6b3fa0}{x})$

$A = \textcolor{#1a6fa0}{7} \times \textcolor{#c0392b}{4} + \textcolor{#1a6fa0}{7} \times \textcolor{#6b3fa0}{x}$

$A = \boxed{28 + 7x}$

🔍 Exemple 2

Développer : $B = \textcolor{#1a6fa0}{2}(\textcolor{#c0392b}{x} - \textcolor{#6b3fa0}{1})$

facteur $k$ premier terme deuxième terme

$B = \textcolor{#1a6fa0}{2}(\textcolor{#c0392b}{x} - \textcolor{#6b3fa0}{1})$

$B = \textcolor{#1a6fa0}{2} \times \textcolor{#c0392b}{x} - \textcolor{#1a6fa0}{2} \times \textcolor{#6b3fa0}{1}$

$B = \boxed{2x - 2}$

2. Opposé d'une expression littérale
📘 Définition

Si une parenthèse est précédée d'un signe $-$, il faut changer le signe de tout ce qui est dans la parenthèse.

Si une parenthèse est précédée d'un signe $+$, il ne faut rien changer.

🔍 Exemple 1

$A = 4x \textcolor{#c0392b}{-} (5x - 6)$

Le signe devant la parenthèse est $-$ → on change tous les signes à l'intérieur :

$A = 4x \textcolor{#c0392b}{-} (\textcolor{#c0392b}{+5x} \textcolor{#c0392b}{- 6})$

$A = 4x \textcolor{#c0392b}{- 5x} \textcolor{#c0392b}{+ 6}$

$A = \boxed{-x + 6}$

$+5x$ devient $\textcolor{#c0392b}{-5x}$ et $-6$ devient $\textcolor{#c0392b}{+6}$.

🔍 Exemple 2

$B = 4x \textcolor{#1b7a40}{+} (5x - 6)$

Le signe devant la parenthèse est $+$ → on ne change rien :

$B = 4x \textcolor{#1b7a40}{+} (\textcolor{#1b7a40}{5x - 6})$

$B = 4x \textcolor{#1b7a40}{+ 5x - 6}$

$B = \boxed{9x - 6}$

IV — Factoriser une somme ou une différence
📘 Définition

Factoriser, c'est transformer une somme ou une différence en produit.

📗 Propriété

$k$, $a$ et $b$ désignent des nombres.

$\textcolor{#1a6fa0}{k}\textcolor{#c0392b}{a} + \textcolor{#1a6fa0}{k}\textcolor{#6b3fa0}{b} = \textcolor{#1a6fa0}{k}(\textcolor{#c0392b}{a} + \textcolor{#6b3fa0}{b})$   et   $\textcolor{#1a6fa0}{k}\textcolor{#c0392b}{a} - \textcolor{#1a6fa0}{k}\textcolor{#6b3fa0}{b} = \textcolor{#1a6fa0}{k}(\textcolor{#c0392b}{a} - \textcolor{#6b3fa0}{b})$
🔍 Exemple 1

Factoriser : $A = \textcolor{#1a6fa0}{2} \times x + \textcolor{#1a6fa0}{2} \times 4$

facteur commun ce qui reste (1er terme) ce qui reste (2e terme)

$A = \textcolor{#1a6fa0}{2} \times \textcolor{#c0392b}{x} + \textcolor{#1a6fa0}{2} \times \textcolor{#6b3fa0}{4}$

$A = \boxed{\textcolor{#1a6fa0}{2}(\textcolor{#c0392b}{x} + \textcolor{#6b3fa0}{4})}$

🔍 Exemple 2

Factoriser : $B = 3x + 6$

facteur commun ce qui reste (1er terme) ce qui reste (2e terme)

On repère que $3x = \textcolor{#1a6fa0}{3} \times \textcolor{#c0392b}{x}$ et $6 = \textcolor{#1a6fa0}{3} \times \textcolor{#6b3fa0}{2}$. Le facteur commun est $\textcolor{#1a6fa0}{3}$.

$B = \textcolor{#1a6fa0}{3} \times \textcolor{#c0392b}{x} + \textcolor{#1a6fa0}{3} \times \textcolor{#6b3fa0}{2}$

$B = \boxed{\textcolor{#1a6fa0}{3}(\textcolor{#c0392b}{x} + \textcolor{#6b3fa0}{2})}$

🔍 Exemple 3

Factoriser : $C = 7x^2 + 14x$

facteur commun ce qui reste (1er terme) ce qui reste (2e terme)

On repère que $7x^2 = \textcolor{#1a6fa0}{7x} \times \textcolor{#c0392b}{x}$ et $14x = \textcolor{#1a6fa0}{7x} \times \textcolor{#6b3fa0}{2}$. Le facteur commun est $\textcolor{#1a6fa0}{7x}$.

$C = \textcolor{#1a6fa0}{7x} \times \textcolor{#c0392b}{x} + \textcolor{#1a6fa0}{7x} \times \textcolor{#6b3fa0}{2}$

$C = \boxed{\textcolor{#1a6fa0}{7x}(\textcolor{#c0392b}{x} + \textcolor{#6b3fa0}{2})}$

V — Démontrer une propriété
1. Égalités d'expressions
📘 Définition

Deux expressions littérales sont égales si elles sont toujours égales, c'est-à-dire si elles sont égales pour n'importe quelle valeur attribuée aux lettres.

📗 Méthode

Pour prouver qu'une égalité est vraie, on développe et réduit chaque membre séparément et on vérifie qu'on obtient la même expression.

🔍 Exemple

Prouver que pour tous les nombres $x$, on a :

$2x(5 + x) + 10 = 47 + x(10 + 2x) - 37$

On développe et réduit chaque membre :

Membre de gauche :

$\textcolor{#1a6fa0}{2x}(\textcolor{#c0392b}{5} + \textcolor{#6b3fa0}{x}) + 10$

$= \textcolor{#1a6fa0}{2x} \times \textcolor{#c0392b}{5} + \textcolor{#1a6fa0}{2x} \times \textcolor{#6b3fa0}{x} + 10$

$= 10x + 2x^2 + 10$

$= \textcolor{#1b7a40}{2x^2 + 10x + 10}$

Membre de droite :

$47 + \textcolor{#1a6fa0}{x}(\textcolor{#c0392b}{10} + \textcolor{#6b3fa0}{2x}) - 37$

$= 47 + \textcolor{#1a6fa0}{x} \times \textcolor{#c0392b}{10} + \textcolor{#1a6fa0}{x} \times \textcolor{#6b3fa0}{2x} - 37$

$= 47 + 10x + 2x^2 - 37$

$= \textcolor{#1b7a40}{2x^2 + 10x + 10}$

Conclusion : Les deux membres donnent $\textcolor{#1b7a40}{2x^2 + 10x + 10}$. L'égalité est donc vraie pour tout nombre $x$.
2. Contre-exemples
📘 Définition

Il suffit de trouver un seul exemple pour lequel deux expressions donnent des résultats différents pour prouver qu'elles ne sont pas égales. Cet exemple s'appelle un contre-exemple.

🔍 Exemple

Léo affirme : « pour tous les nombres $a$ et $b$, on a : $(a + b)^2 = a^2 + b^2$ ». A-t-il raison ?

On essaie avec $\textcolor{#1a6fa0}{a = 1}$ et $\textcolor{#c0392b}{b = 1}$ :

Membre de gauche :

$(\textcolor{#1a6fa0}{a} + \textcolor{#c0392b}{b})^2 = (\textcolor{#1a6fa0}{1} + \textcolor{#c0392b}{1})^2$

$= 2^2 = \textcolor{#6b3fa0}{4}$

Membre de droite :

$\textcolor{#1a6fa0}{a}^2 + \textcolor{#c0392b}{b}^2 = \textcolor{#1a6fa0}{1}^2 + \textcolor{#c0392b}{1}^2$

$= 1 + 1 = \textcolor{#6b3fa0}{2}$

Conclusion : $\textcolor{#6b3fa0}{4} \neq \textcolor{#6b3fa0}{2}$, donc Léo a tort. On a trouvé un contre-exemple : pour $a = 1$ et $b = 1$, $(a + b)^2 \neq a^2 + b^2$.
Bilan
✅ Ce que je dois retenir
  • Simplifier : on supprime le signe $\times$ devant une lettre ou une parenthèse.
  • Réduire : on regroupe les termes de même nature ($\textcolor{#1a6fa0}{a}x + \textcolor{#c0392b}{b}x = (\textcolor{#1a6fa0}{a}+\textcolor{#c0392b}{b})x$).
  • Développer : $\textcolor{#1a6fa0}{k}(\textcolor{#c0392b}{a}+\textcolor{#6b3fa0}{b}) = \textcolor{#1a6fa0}{k}\textcolor{#c0392b}{a} + \textcolor{#1a6fa0}{k}\textcolor{#6b3fa0}{b}$.
  • Parenthèses : signe $\textcolor{#c0392b}{-}$ devant → on change les signes ; signe $\textcolor{#1b7a40}{+}$ devant → on ne change rien.
  • Factoriser : $\textcolor{#1a6fa0}{k}\textcolor{#c0392b}{a} + \textcolor{#1a6fa0}{k}\textcolor{#6b3fa0}{b} = \textcolor{#1a6fa0}{k}(\textcolor{#c0392b}{a}+\textcolor{#6b3fa0}{b})$ (opération inverse du développement).
  • Prouver une égalité : développer et réduire chaque membre.
  • Contre-exemple : un seul cas suffit pour invalider une affirmation.
⚠️ Erreurs fréquentes
  • Confondre $2x \textcolor{#1b7a40}{+} 3x = 5x$ ✅ avec $2x \textcolor{#c0392b}{\times} 3x = 5x$ ❌ (le vrai résultat est $6x^2$).
  • Oublier de changer les signes quand on supprime des parenthèses précédées de $-$.
  • Croire que $(a + b)^2 = a^2 + b^2$ : c'est faux !
  • Écrire $1x$ au lieu de $x$.
