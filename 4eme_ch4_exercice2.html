× et ÷ : même méthode Le signe, puis la valeur

📌 Ce qu'il faut savoir

La méthode : le signe, puis la valeur
① Le signe. Je compte les « − ». Chaque « − » retourne le résultat, comme un interrupteur. Un nombre pair de « − » → résultat positif ; un nombre impair → résultat négatif.
② La valeur. Je multiplie (ou divise) les nombres sans leurs signes.
👉 Jamais les deux en même temps. Et \(\times\) et \(\div\) se traitent exactement pareil.
⚠️ Deux mondes, deux rôles du « − »
Dans une somme, chaque « − » est une quantité (une dette) : on fait le bilan.
Dans un produit, chaque « − » est un retournement : on compte s'il y en a un nombre pair ou impair.
👉 Ne mélange pas les deux méthodes !

Exercice 1 / 5

Multiplier 2 facteurs
✓ Vu

Calcule.

a)\((+4)\times(-3)\)
b)\((-5)\times(-2)\)
c)\((-6)\times(+7)\)

💡 De quoi ai-je besoin ici ?

Dans le monde multiplicatif, rien à griser : les deux étapes servent toujours, et dans cet ordre — jamais en même temps.

①LE SIGNE : je compte les « − ». Pair → + (bleu), impair → − (rouge).★ d'abord
②LA VALEUR : je multiplie les nombres sans leurs signes.★ ensuite
Pour le a) : un seul « − ». Un interrupteur → le résultat est retourné une fois → il sera négatif (rouge). Ensuite seulement, je calcule \(4\times3\).
Chaque « − » est un interrupteur qui retourne le résultat. Pair → on revient à l'endroit (positif, bleu). Impair → à l'envers (négatif, rouge).
a)
\((+4)\times(\colorbox{#ffe9a6}{$-$}3)\)1 interrupteur
① Le signe
1 fois « − » → impair → négatif
② La valeur
\(4\times3=12\)
\(=\textcolor{#c0283f}{-12}\)
b)
\((\colorbox{#ffe9a6}{$-$}5)\times(\colorbox{#ffe9a6}{$-$}2)\)2 interrupteurs
① Le signe
2 fois « − » → pair → positif
② La valeur
\(5\times2=10\)
\(=\textcolor{#1d5fa8}{+10}\)
c)
\((\colorbox{#ffe9a6}{$-$}6)\times(+7)\)1 interrupteur
① Le signe
1 fois « − » → impair → négatif
② La valeur
\(6\times7=42\)
\(=\textcolor{#c0283f}{-42}\)

Exercice 2 / 5

Diviser Même méthode que ×
✓ Vu

Calcule.

a)\((-12)\div(+3)\)
b)\((+20)\div(-4)\)
c)\((-18)\div(-6)\)

💡 De quoi ai-je besoin ici ?

La division marche exactement comme la multiplication : rien ne change.

①LE SIGNE : je compte les « − ». Pair → + (bleu), impair → − (rouge).★ d'abord
②LA VALEUR : je divise les nombres sans leurs signes.★ ensuite
Ne change rien à tes habitudes de la multiplication : compte les « − » pour le signe, puis divise les nombres. Pour le c) : deux « − » → pair → positif.
a)
\((\colorbox{#ffe9a6}{$-$}12)\div(+3)\)1 interrupteur
① Le signe
1 fois « − » → impair → négatif
② La valeur
\(12\div3=4\)
\(=\textcolor{#c0283f}{-4}\)
b)
\((+20)\div(\colorbox{#ffe9a6}{$-$}4)\)1 interrupteur
① Le signe
1 fois « − » → impair → négatif
② La valeur
\(20\div4=5\)
\(=\textcolor{#c0283f}{-5}\)
c)
\((\colorbox{#ffe9a6}{$-$}18)\div(\colorbox{#ffe9a6}{$-$}6)\)2 interrupteurs
① Le signe
2 fois « − » → pair → positif
② La valeur
\(18\div6=3\)
\(=\textcolor{#1d5fa8}{+3}\)

Exercice 3 / 5

Multiplier Plusieurs facteurs
✓ Vu

Calcule.

a)\((-2)\times(+3)\times(-4)\)
b)\((-1)\times(-2)\times(-5)\)
c)\((+2)\times(-3)\times(-1)\times(-5)\)

💡 De quoi ai-je besoin ici ?

Beaucoup de facteurs, mais la même méthode : compter les « − » suffit, même avec 3 ou 4 nombres.

①LE SIGNE : je compte TOUS les « − ». Pair → + (bleu), impair → − (rouge).★ d'abord
②LA VALEUR : je multiplie tous les nombres sans leurs signes.★ ensuite
Chaque « − » retourne le résultat. Deux « − » se neutralisent (on revient à l'endroit). Il suffit donc de savoir s'il reste un retournement « en trop » → c'est la parité : pair ou impair.
a)
\((\colorbox{#ffe9a6}{$-$}2)\times(+3)\times(\colorbox{#ffe9a6}{$-$}4)\)2 interrupteurs
① Le signe
2 fois « − » → pair → positif
② La valeur
\(2\times3\times4=24\)
\(=\textcolor{#1d5fa8}{+24}\)
b)
\((\colorbox{#ffe9a6}{$-$}1)\times(\colorbox{#ffe9a6}{$-$}2)\times(\colorbox{#ffe9a6}{$-$}5)\)3 interrupteurs
① Le signe
3 fois « − » → impair → négatif
② La valeur
\(1\times2\times5=10\)
\(=\textcolor{#c0283f}{-10}\)
c)
\((+2)\times(\colorbox{#ffe9a6}{$-$}3)\times(\colorbox{#ffe9a6}{$-$}1)\times(\colorbox{#ffe9a6}{$-$}5)\)3 interrupteurs
① Le signe
3 fois « − » → impair → négatif
② La valeur
\(2\times3\times1\times5=30\)
\(=\textcolor{#c0283f}{-30}\)

Exercice 4 / 5

Mélanger × et ÷ Même méthode
✓ Vu

Calcule.

a)\((-24)\div(+4)\times(-2)\)
b)\((+30)\div(-5)\div(-2)\)
c)\((-8)\times(-3)\div(-6)\)

💡 De quoi ai-je besoin ici ?

× et ÷ mélangés : aucune règle nouvelle. On compte les « − » sur tout le calcul.

①LE SIGNE : je compte les « − » de tout le calcul (× comme ÷). Pair → + , impair → −.★ d'abord
②LA VALEUR : je calcule de gauche à droite avec les nombres sans signes.★ ensuite
Pour la valeur, calcule dans l'ordre d'écriture. Ex a) : \(24\div4=6\), puis \(6\times2=12\). Le signe, lui, se décide à part, en comptant les « − ».
a)
\((\colorbox{#ffe9a6}{$-$}24)\div(+4)\times(\colorbox{#ffe9a6}{$-$}2)\)2 interrupteurs
① Le signe
2 fois « − » → pair → positif
② La valeur
\(24\div4=6\), puis \(6\times2=12\)
\(=\textcolor{#1d5fa8}{+12}\)
b)
\((+30)\div(\colorbox{#ffe9a6}{$-$}5)\div(\colorbox{#ffe9a6}{$-$}2)\)2 interrupteurs
① Le signe
2 fois « − » → pair → positif
② La valeur
\(30\div5=6\), puis \(6\div2=3\)
\(=\textcolor{#1d5fa8}{+3}\)
c)
\((\colorbox{#ffe9a6}{$-$}8)\times(\colorbox{#ffe9a6}{$-$}3)\div(\colorbox{#ffe9a6}{$-$}6)\)3 interrupteurs
① Le signe
3 fois « − » → impair → négatif
② La valeur
\(8\times3=24\), puis \(24\div6=4\)
\(=\textcolor{#c0283f}{-4}\)

Exercice 5 / 5

Juste le signe Produits géants
✓ Vu

On ne peut pas tout calculer : trouve seulement le SIGNE du résultat.

a)\((-1)\times(-1)\times\cdots\times(-1)\) avec 473 facteurs tous égaux à \(-1\). Combien vaut ce produit ?
b)On multiplie 43 nombres relatifs (aucun nul), dont 15 sont positifs. Quel est le signe du résultat ?
c)On multiplie 60 nombres relatifs (aucun nul), dont 7 sont négatifs. Quel est le signe du résultat ?

💡 De quoi ai-je besoin ici ?

Ici, seul le signe est demandé : inutile (ou impossible) de calculer la valeur. Tout se joue sur la parité du nombre de « − ».

①LE SIGNE : je compte les « − » et je regarde s'il y en a un nombre pair ou impair.★ tout est là
②LA VALEUR : je multiplie les nombres sans leurs signes.— pas demandée ici
Un nombre est pair s'il se termine par 0, 2, 4, 6 ou 8 ; impair s'il se termine par 1, 3, 5, 7 ou 9. Pour b), commence par trouver combien il y a de négatifs : \(43-15\).
Pour le signe, seuls les « − » comptent — et seule leur parité compte. Les retournements s'annulent deux par deux : s'il en reste un « en trop » (impair), le résultat est négatif ; sinon (pair), il est positif. Pas besoin de la valeur.
a)
① Le signe
473 fois « − » → 473 est impair → négatif
② La valeur
\(1\times1\times\cdots\times1=1\)
\(=\textcolor{#c0283f}{-1}\)

473 se termine par 3 : c'est impair. Il reste un retournement « en trop » → résultat négatif.

b)
① Le signe
négatifs : \(43-15=28\) → 28 est pair → positif
② La valeur
non demandée
→ le produit est positif

Seuls les négatifs décident du signe : 28, c'est pair → les retournements se neutralisent deux par deux.

c)
① Le signe
7 négatifs → 7 est impair → négatif
② La valeur
non demandée
→ le produit est négatif

Les 53 nombres positifs ne changent rien au signe : seuls les « − » comptent.
