Chasles Somme Vecteur opposé

📌 L'essentiel à retenir

① Relation de Chasles
Pour tous points \(A\), \(B\), \(C\) : \[\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}\] Le point du milieu (\(B\)) apparaît en arrivée et en départ : il se « simplifie ». Ce qui reste, c'est de l'extrémité gauche à l'extrémité droite.
② Vecteur opposé
\(-\overrightarrow{AB} = \overrightarrow{BA}\). En pratique, pour transformer une soustraction en addition, on écrit : \[\overrightarrow{AB} - \overrightarrow{CB} = \overrightarrow{AB} + \overrightarrow{BC}\] puis on applique Chasles.
③ Astuce : chaîner les lettres
Pour simplifier une somme, regarder si les lettres se « touchent » : dans \(\overrightarrow{AB} + \overrightarrow{BC}\), le \(B\) de fin et le \(B\) de début se touchent et disparaissent. Même chose avec plusieurs termes successifs.

Exercice 1 / 6

Chasles direct Application immédiate
✓ Vu

Simplifier chaque expression en un seul vecteur. Le schéma ci-dessous illustre le principe de Chasles pour t'aider à démarrer.

Le point \(B\) (entouré) apparaît en arrivée du premier vecteur et en départ du second : il disparaît.

a) \(\overrightarrow{AB} + \overrightarrow{BC}\)
b) \(\overrightarrow{MN} + \overrightarrow{NP}\)
c) \(\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CD}\)
d) \(\overrightarrow{PQ} + \overrightarrow{QR} + \overrightarrow{RS} + \overrightarrow{ST}\)

💡 Indices

Dans \(\overrightarrow{AB} + \overrightarrow{BC}\), la lettre \(B\) apparaît deux fois de suite (fin du premier, début du second) : elle disparaît. Il reste \(\overrightarrow{AC}\). Appliquer la même logique en chaîne pour les expressions à plusieurs termes.
a)
\(\overrightarrow{A\mathbf{B}} + \overrightarrow{\mathbf{B}C}\) : le \(B\) se simplifie → \(\overrightarrow{AC}\)
b)
\(\overrightarrow{M\mathbf{N}} + \overrightarrow{\mathbf{N}P}\) : le \(N\) se simplifie → \(\overrightarrow{MP}\)
c)
\(\overrightarrow{A\mathbf{B}} + \overrightarrow{\mathbf{B}\mathbf{C}} + \overrightarrow{\mathbf{C}D}\) : \(B\) puis \(C\) se simplifient → \(\overrightarrow{AD}\)
d)
\(\overrightarrow{P\mathbf{Q}} + \overrightarrow{\mathbf{Q}\mathbf{R}} + \overrightarrow{\mathbf{R}\mathbf{S}} + \overrightarrow{\mathbf{S}T}\) : \(Q\), \(R\), \(S\) se simplifient → \(\overrightarrow{PT}\)
Règle générale : dans une chaîne \(\overrightarrow{AA_1} + \overrightarrow{A_1 A_2} + \cdots + \overrightarrow{A_{n-1}B}\), toutes les lettres intermédiaires se simplifient et il reste \(\overrightarrow{AB}\).

Exercice 2 / 6

Circuit fermé Vecteur nul
✓ Vu

Simplifier chaque expression.

a) \(\overrightarrow{AB} + \overrightarrow{BA}\)
b) \(\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CA}\)
c) \(\overrightarrow{MN} + \overrightarrow{NP} + \overrightarrow{PM}\)
d) \(\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CD} + \overrightarrow{DA}\)

💡 Indices

Appliquer Chasles en chaîne. Si, après simplification, il reste \(\overrightarrow{XX}\) pour un même point \(X\), ce vecteur est le vecteur nul \(\vec{0}\) : on reste sur place.
a)
\(\overrightarrow{A\mathbf{B}} + \overrightarrow{\mathbf{B}A}\) : \(B\) se simplifie → \(\overrightarrow{AA} =\) \(\vec{0}\)
b)
\(\overrightarrow{A\mathbf{B}} + \overrightarrow{\mathbf{B}\mathbf{C}} + \overrightarrow{\mathbf{C}A}\) : \(B\) et \(C\) se simplifient → \(\overrightarrow{AA} =\) \(\vec{0}\)
c)
\(\overrightarrow{M\mathbf{N}} + \overrightarrow{\mathbf{N}\mathbf{P}} + \overrightarrow{\mathbf{P}M}\) : \(N\) et \(P\) se simplifient → \(\overrightarrow{MM} =\) \(\vec{0}\)
d)
\(\overrightarrow{A\mathbf{B}} + \overrightarrow{\mathbf{B}\mathbf{C}} + \overrightarrow{\mathbf{C}\mathbf{D}} + \overrightarrow{\mathbf{D}A}\) → \(\overrightarrow{AA} =\) \(\vec{0}\)
À retenir : tout « circuit fermé » (on revient au point de départ) donne le vecteur nul. La première et la dernière lettre sont identiques.

Exercice 3 / 6

Vecteur opposé Soustraction
✓ Vu

Simplifier chaque expression en un seul vecteur. (Rappel : \(-\overrightarrow{CB} = \overrightarrow{BC}\).)

a) \(\overrightarrow{AB} - \overrightarrow{CB}\)
b) \(\overrightarrow{AB} - \overrightarrow{AC}\)
c) \(\overrightarrow{MA} - \overrightarrow{MB}\)
d) \(\overrightarrow{AC} + \overrightarrow{DB} - \overrightarrow{DC}\)

💡 Indices

Transformer d'abord chaque soustraction en addition : \(-\overrightarrow{XY} = +\overrightarrow{YX}\). Ensuite, vérifier si les lettres « bout à bout » peuvent se simplifier par Chasles.
En d) : \(-\overrightarrow{DC} = \overrightarrow{CD}\). On obtient \(\overrightarrow{AC} + \overrightarrow{DB} + \overrightarrow{CD}\). Réordonner pour faire apparaître des lettres qui se touchent : \(\overrightarrow{DB} + \overrightarrow{CD} = \overrightarrow{CD} + \overrightarrow{DB}\)… repérer les chaînes possibles.
a) \(\overrightarrow{AB} - \overrightarrow{CB}\)
Transformer\(-\overrightarrow{CB} = \overrightarrow{BC}\)
Chasles\(\overrightarrow{A\mathbf{B}} + \overrightarrow{\mathbf{B}C}\ \to\) \(\overrightarrow{AC}\)
b) \(\overrightarrow{AB} - \overrightarrow{AC}\)
Transformer\(-\overrightarrow{AC} = \overrightarrow{CA}\)
Réordonner\(\overrightarrow{CA} + \overrightarrow{AB}\) : \(A\) se simplifie
Résultat\(\overrightarrow{CB}\)
c) \(\overrightarrow{MA} - \overrightarrow{MB}\)
Transformer\(-\overrightarrow{MB} = \overrightarrow{BM}\)
Réordonner\(\overrightarrow{BM} + \overrightarrow{MA}\) : \(M\) se simplifie
Résultat\(\overrightarrow{BA}\)
d) \(\overrightarrow{AC} + \overrightarrow{DB} - \overrightarrow{DC}\)
Transformer\(-\overrightarrow{DC} = \overrightarrow{CD}\)
Regrouper\(\overrightarrow{AC} + (\overrightarrow{CD} + \overrightarrow{DB})\)
Chasles int.\(\overrightarrow{C\mathbf{D}} + \overrightarrow{\mathbf{D}B} = \overrightarrow{CB}\)
Chasles final\(\overrightarrow{A\mathbf{C}} + \overrightarrow{\mathbf{C}B} =\) \(\overrightarrow{AB}\)
⚠ Méthode : toujours transformer les soustractions en additions avant d'appliquer Chasles. Ne jamais tenter de « simplifier » directement une soustraction de vecteurs.

Exercice 4 / 6

Décomposer Passer par un point
✓ Vu

Exprimer chaque vecteur en faisant intervenir le point indiqué entre parenthèses.

a) \(\overrightarrow{AC}\) en passant par \(B\)
b) \(\overrightarrow{PR}\) en passant par \(Q\)
c) \(\overrightarrow{AD}\) en passant par \(B\) puis \(C\)
d) \(\overrightarrow{AB}\) en passant par \(M\), en sachant que \(M\) est le milieu de \([AB]\)

💡 Indices

Pour exprimer \(\overrightarrow{AC}\) en passant par \(B\), il suffit d'intercaler \(B\) : \(\overrightarrow{AC} = \overrightarrow{AB} + \overrightarrow{BC}\). C'est Chasles dans le sens inverse : on « crée » un point intermédiaire.
Puisque \(M\) est le milieu de \([AB]\), on a \(\overrightarrow{AM} = \overrightarrow{MB}\) (même déplacement de \(A\) à \(M\) que de \(M\) à \(B\)). Donc \(\overrightarrow{AB} = \overrightarrow{AM} + \overrightarrow{MB} = 2\overrightarrow{AM}\).
a) \(\overrightarrow{AC}\) en passant par \(B\)
\(\overrightarrow{AC} = \overrightarrow{AB} + \overrightarrow{BC}\)
b) \(\overrightarrow{PR}\) en passant par \(Q\)
\(\overrightarrow{PR} = \overrightarrow{PQ} + \overrightarrow{QR}\)
c) \(\overrightarrow{AD}\) en passant par \(B\) puis \(C\)
\(\overrightarrow{AD} = \overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CD}\)
d) \(\overrightarrow{AB}\) en passant par le milieu \(M\)

Puisque \(M\) est le milieu de \([AB]\) : \(\overrightarrow{AM} = \overrightarrow{MB}\).

Chasles\(\overrightarrow{AB} = \overrightarrow{AM} + \overrightarrow{MB}\)
Milieu\(\overrightarrow{MB} = \overrightarrow{AM}\), donc \(\overrightarrow{AB} = \overrightarrow{AM} + \overrightarrow{AM}\)
Résultat\(\overrightarrow{AB} = 2\overrightarrow{AM}\)
À retenir : intercaler un point intermédiaire dans un vecteur, c'est appliquer Chasles « à l'envers » — on ajoute un point pour décomposer, pas pour simplifier.

Exercice 5 / 6

Chasles Avec coordonnées
✓ Vu

On donne \(A(1\,;\,2)\), \(B(4\,;\,5)\), \(C(-1\,;\,3)\), \(D(2\,;\,0)\).

1) Calculer les coordonnées de \(\overrightarrow{AB}\), \(\overrightarrow{BC}\) et \(\overrightarrow{AC}\).
2) Vérifier numériquement que \(\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}\).
3) Calculer \(\overrightarrow{AB} + \overrightarrow{BD} - \overrightarrow{CD}\) en utilisant Chasles.

💡 Indices

Pour vérifier \(\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}\) numériquement, additionner les coordonnées de \(\overrightarrow{AB}\) et \(\overrightarrow{BC}\) composante par composante, et vérifier qu'on obtient bien celles de \(\overrightarrow{AC}\).
Transformer d'abord \(-\overrightarrow{CD} = \overrightarrow{DC}\), puis chercher les lettres qui se touchent dans la somme \(\overrightarrow{AB} + \overrightarrow{BD} + \overrightarrow{DC}\).
1) Coordonnées
AB\(\overrightarrow{AB}\binom{4-1}{5-2} = \binom{3}{3}\)
BC\(\overrightarrow{BC}\binom{-1-4}{3-5} = \binom{-5}{-2}\)
AC\(\overrightarrow{AC}\binom{-1-1}{3-2} = \binom{-2}{1}\)
2) Vérification numérique
AB + BC\(\binom{3}{3} + \binom{-5}{-2} = \binom{3+(-5)}{3+(-2)} = \binom{-2}{1}\)
AC\(\binom{-2}{1}\) ✓

Les coordonnées coïncident : la relation de Chasles est bien vérifiée numériquement.

3) \(\overrightarrow{AB} + \overrightarrow{BD} - \overrightarrow{CD}\)
Transformer\(-\overrightarrow{CD} = \overrightarrow{DC}\)
Somme\(\overrightarrow{A\mathbf{B}} + \overrightarrow{\mathbf{B}\mathbf{D}} + \overrightarrow{\mathbf{D}C}\)
Chasles\(B\) et \(D\) se simplifient → \(\overrightarrow{AC}\)

Exercice 6 / 6

Synthèse Raisonnement
✓ Vu

\(ABCD\) est un parallélogramme. Simplifier les expressions suivantes en utilisant les propriétés du parallélogramme et la relation de Chasles.

a) \(\overrightarrow{AB} + \overrightarrow{AD}\) (indice : penser à la diagonale)
b) \(\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CD} + \overrightarrow{DA}\)
c) \(\overrightarrow{CA} + \overrightarrow{AB}\)
d) \(\overrightarrow{AC} - \overrightarrow{BC}\)

💡 Indices

Dans un parallélogramme \(ABCD\), la somme \(\overrightarrow{AB} + \overrightarrow{AD}\) correspond à la diagonale issue de \(A\). Utiliser la règle du parallélogramme : si \(ABCD\) est un parallélogramme, alors \(\overrightarrow{AB} + \overrightarrow{AD} = \overrightarrow{AC}\).
Transformer \(-\overrightarrow{BC} = \overrightarrow{CB}\), puis appliquer Chasles à \(\overrightarrow{AC} + \overrightarrow{CB}\).
a) \(\overrightarrow{AB} + \overrightarrow{AD}\)

Dans un parallélogramme, la règle du parallélogramme donne directement :

\(\overrightarrow{AB} + \overrightarrow{AD} = \overrightarrow{AC}\) (la diagonale issue de \(A\))
b) \(\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CD} + \overrightarrow{DA}\)
\(\overrightarrow{A\mathbf{B}} + \overrightarrow{\mathbf{B}\mathbf{C}} + \overrightarrow{\mathbf{C}\mathbf{D}} + \overrightarrow{\mathbf{D}A}\) : circuit fermé → \(\vec{0}\)
c) \(\overrightarrow{CA} + \overrightarrow{AB}\)
\(\overrightarrow{C\mathbf{A}} + \overrightarrow{\mathbf{A}B}\) : \(A\) se simplifie → \(\overrightarrow{CB}\)
d) \(\overrightarrow{AC} - \overrightarrow{BC}\)
Transformer\(-\overrightarrow{BC} = \overrightarrow{CB}\)
Chasles\(\overrightarrow{A\mathbf{C}} + \overrightarrow{\mathbf{C}B}\) : \(C\) se simplifie → \(\overrightarrow{AB}\)
Bilan : avec Chasles, tout se ramène à repérer les lettres qui se touchent (fin d'un vecteur = début du suivant). Transformer d'abord les soustractions, puis chercher les simplifications.
