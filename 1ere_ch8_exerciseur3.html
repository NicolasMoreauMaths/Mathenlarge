Contexte — simuler le hasard avec Python La fonction random.random() renvoie un nombre décimal tiré au hasard entre 0 et 1 (valeur différente à chaque appel). En comparant ce nombre à une probabilité p, on simule n'importe quelle épreuve aléatoire — sans dé, sans pièce, sans rien.
💡 L'idée clé

random.random() < 0.5 est vrai environ une fois sur deux — comme pile ou face.
random.random() < 0.7 est vrai environ 7 fois sur 10 — comme un événement de probabilité 0,7.
En répétant cela des milliers de fois dans une boucle, on estime des probabilités : c'est la méthode Monte-Carlo.

❓ Exercice 1 — Lire et comprendre

Voici un programme qui simule 1 000 lancers d'une pièce équilibrée et compte le nombre de « pile ». Que représente la variable compteur à la fin du programme ?

pile_ou_face.py
import random
compteur = 0
for i in range(1000) :
    if random.random() < 0.5 :
        compteur = compteur + 1
print(compteur)
AToujours exactement 500, car P(pile) = 0,5
BLe nombre de fois où random.random() a renvoyé exactement 0,5
CLe nombre de lancers simulés « pile », un résultat aléatoire proche de 500
DLe nombre de lancers simulés « face »
✅ Bonne réponse : C.

compteur augmente d'1 chaque fois que random.random() renvoie un nombre strictement inférieur à 0,5, ce qui arrive environ une fois sur deux. Le résultat est aléatoire — proche de 500 mais rarement exactement 500. En relançant le programme on obtiendrait une valeur différente. La réponse B est fausse : random.random() tire dans [0 ; 1[ en continu, la probabilité d'obtenir exactement 0,5 est nulle.

✅ Bonne réponse : D.

Contexte — lancer de deux dés On lance simultanément deux dés équilibrés à 6 faces. En Python, random.randint(1, 6) simule le lancer d'un dé (renvoie un entier entre 1 et 6 inclus). On s'intéresse à la somme des deux dés et à d'autres événements.
⌨️ Exercice 6 — Écrire

Écris un programme qui simule 10 000 lancers de deux dés et estime la probabilité d'obtenir une somme égale à 7.

Tu auras besoin de : import random, random.randint(1, 6), une boucle for, un compteur, et un print de la fréquence.

La valeur théorique est 6/36 ≈ 0,167 — vérifie que ta simulation s'en approche.

exercice6.py
corrigé6.py
import random
N        = 10000
compteur = 0
for i in range(N) :
    d1 = random.randint(1, 6)
    d2 = random.randint(1, 6)
    if d1 + d2 == 7 :
        compteur = compteur + 1
print(compteur / N)

Les 6 combinaisons gagnantes sont (1,6), (2,5), (3,4), (4,3), (5,2), (6,1) sur 36 possibles → P = 6/36 ≈ 0,167. La simulation devrait donner un résultat proche.

⌨️ Exercice 7 — Aller plus loin

Modifie ton programme pour estimer la probabilité d'obtenir un double (les deux dés affichent la même valeur). Affiche la fréquence obtenue pour N = 100, N = 1 000, puis N = 100 000 dans trois print() séparés.

Observe comment la fréquence se stabilise autour de la valeur théorique quand N augmente : c'est la loi des grands nombres.

exercice7.py
corrigé7.py
import random

def simul(N) :
    compteur = 0
    for i in range(N) :
        d1 = random.randint(1, 6)
        d2 = random.randint(1, 6)
        if d1 == d2 :
            compteur = compteur + 1
    return compteur / N

print(simul(100))
print(simul(1000))
print(simul(100000))

Il y a 6 doubles sur 36 issues → P(double) = 1/6 ≈ 0,167. Avec N = 100, la fréquence peut varier entre 0,10 et 0,24 ; avec N = 100 000, elle sera généralement entre 0,165 et 0,169. C'est la loi des grands nombres en action. La version avec une fonction def simul(N) est élégante mais pas obligatoire — trois boucles séparées sont aussi correctes.
