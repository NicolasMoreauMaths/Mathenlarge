📚 Vocabulaire — les mots clés
Raison q
Le nombre par lequel on multiplie à chaque fois. Se calcule : q = un+1 ÷ un.
Suite géométrique
Suite où le rapport q entre deux termes consécutifs est constant (toujours le même).

📚 Rappel — comment trouver q ?
Termes consécutifs
q = un+1 ÷ un. Divise un terme par le précédent.
Termes non consécutifs
Entre u0 et u2 il y a 2 fois q, donc u2 = u0 × q².

📋 Ce que tu as découvert
✓ Une suite géométrique multiplie toujours par le même nombre d'un terme au suivant.
✓ Ce nombre s'appelle la raison q. Elle se calcule : q = un+1 ÷ un.
✓ La relation de récurrence est un+1 = un × q.
✓ Si q > 1 et u0 > 0 : croissante. Si 0 < q < 1 et u0 > 0 : décroissante. Si q = 1 : constante. Si q < 0 : les termes alternent de signe.
✓ La formule du terme général : un = u0 × qn.
✓ Différence clé avec les suites arithmétiques : on multiplie (et non on additionne).
