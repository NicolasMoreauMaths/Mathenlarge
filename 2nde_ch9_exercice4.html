📌 L'essentiel à avoir en tête

Trouver b — 4 étapes
  • 1Écrire \(f(x) = ax + b\) avec \(a\) déjà connu.
  • 2Choisir un point connu \((x_0\,;\,y_0)\).
  • 3Substituer : \(y_0 = a \cdot x_0 + b\).
  • 4Résoudre pour \(b\) (méthode des flèches).
Méthode complète (a inconnu)
  • 1Calculer \(a = \dfrac{y_2 - y_1}{x_2 - x_1}\).
  • 2Injecter un point pour trouver \(b\).
  • 3Écrire \(f(x) = ax + b\) et vérifier.
⚠ Vérification
Toujours vérifier avec le second point : si \(f(x_2) = y_2\), le calcul est juste. Une erreur de signe sur \(b\) est très fréquente !

Exercice 1 / 5

Trouver b a est donné
✓ Vu

Pour chaque fonction affine, \(a\) est donné ainsi qu'un point de la droite. Trouver \(b\) puis écrire l'expression complète de la fonction.

a)
\(a = 3\), \(f(2) = 11\)
b)
\(a = -2\), \(g(1) = 5\)
c)
\(a = \dfrac{1}{2}\), \(h(4) = 3\)
d)
\(a = -1\), \(k(-3) = 4\)

💡 Indices

Pour a) : on sait \(a = 3\) donc \(f(x) = 3x + b\). Le point \(f(2) = 11\) signifie \(x = 2\) et \(y = 11\). On substitue : \(11 = 3 \times 2 + b\), et on résout.
Pour c) : \(h(x) = \frac{1}{2}x + b\). On substitue \(x = 4\), \(y = 3\) : \(3 = \frac{1}{2} \times 4 + b = 2 + b\). Il ne reste plus qu'à isoler \(b\).

Exercice 2 / 5

Trouver b Valeurs négatives
✓ Vu

Même consigne. Attention aux signes : \(b\) peut être négatif ou nul.

a)
\(a = 4\), \(f(3) = 5\)
b)
\(a = -3\), \(g(-2) = 1\)
c)
\(a = 2\), \(h(0) = -4\)
d)
\(a = \dfrac{3}{2}\), \(k(4) = 7\)

💡 Indices

Pour c), le point donné est \((0\,;\,-4)\). Or \(f(0) = a \times 0 + b = b\). Donc on lit directement \(b\) sans calcul !
Si après substitution tu obtiens \(b = -7\), n'hésite pas : \(b\) peut tout à fait être négatif. La droite coupe alors l'axe des ordonnées en dessous de l'origine.
a) a = 4, f(3) = 5

\(f(x) = 4x + b\). On injecte \((3\,;\,5)\) : \(5 = 4 \times 3 + b = 12 + b\).

\(b\) \(+ 12\) \(= 5\)
\(-12\)
\(-12\)
\(b = -7\)
\(b = -7\) → \(f(x) = 4x - 7\). Vérif : \(f(3) = 12 - 7 = 5\) ✓
b) a = −3, g(−2) = 1

\(g(x) = -3x + b\). On injecte \((-2\,;\,1)\) : \(1 = -3 \times (-2) + b = 6 + b\).

\(b\) \(+ 6\) \(= 1\)
\(-6\)
\(-6\)
\(b = -5\)
\(b = -5\) → \(g(x) = -3x - 5\). Vérif : \(g(-2) = 6 - 5 = 1\) ✓
c) a = 2, h(0) = −4
Astuce : \(h(0) = 2 \times 0 + b = b\). Donc \(b\) se lit directement : \(b = -4\).
\(b = -4\) → \(h(x) = 2x - 4\). Vérif : \(h(0) = 0 - 4 = -4\) ✓
d) a = 3/2, k(4) = 7

\(k(x) = \frac{3}{2}x + b\). On injecte \((4\,;\,7)\) : \(7 = \frac{3}{2} \times 4 + b = 6 + b\).

\(b\) \(+ 6\) \(= 7\)
\(-6\)
\(-6\)
\(b = 1\)
\(b = 1\) → \(k(x) = \dfrac{3}{2}x + 1\). Vérif : \(k(4) = 6 + 1 = 7\) ✓

Exercice 3 / 5

Méthode complète Deux points donnés
✓ Vu

Pour chaque fonction affine, deux points sont donnés. Déterminer l'expression complète \(f(x) = ax + b\).

a)
\(f(1) = 5\) et \(f(3) = 11\)
b)
\(g(0) = -1\) et \(g(4) = 7\)
c)
\(h(2) = 3\) et \(h(6) = -1\)
d)
\(k(-1) = 0\) et \(k(3) = 6\)

💡 Indices

Pour b), l'un des points est \((0\,;\,-1)\). Or \(g(0) = b\) directement. On obtient \(b\) sans équation !
Toujours calculer \(a\) en premier avec la formule \(\frac{y_2 - y_1}{x_2 - x_1}\), puis injecter un seul point pour trouver \(b\).
a) f(1) = 5 et f(3) = 11

Étape 1 — Calcul de a

Formule\(a = \dfrac{11 - 5}{3 - 1} = \dfrac{6}{2} = 3\)

Étape 2 — Calcul de b

On injecte \((1\,;\,5)\) dans \(f(x) = 3x + b\) : \(5 = 3 + b\).

\(b\) \(+ 3\) \(= 5\)
\(-3\)
\(-3\)
\(b = 2\)
\(f(x) = 3x + 2\). Vérif : \(f(3) = 9 + 2 = 11\) ✓
b) g(0) = −1 et g(4) = 7

Étape 1 — Calcul de a

Formule\(a = \dfrac{7 - (-1)}{4 - 0} = \dfrac{8}{4} = 2\)

Étape 2 — Calcul de b

Astuce : le point \((0\,;\,-1)\) donne directement \(b = g(0) = -1\).
\(g(x) = 2x - 1\). Vérif : \(g(4) = 8 - 1 = 7\) ✓
c) h(2) = 3 et h(6) = −1

Étape 1 — Calcul de a

Formule\(a = \dfrac{-1 - 3}{6 - 2} = \dfrac{-4}{4} = -1\)

Étape 2 — Calcul de b

On injecte \((2\,;\,3)\) dans \(h(x) = -x + b\) : \(3 = -2 + b\).

\(- 2\) \(+ b = 3\)
\(+2\)
\(+2\)
\(b = 5\)
\(h(x) = -x + 5\). Vérif : \(h(6) = -6 + 5 = -1\) ✓
d) k(−1) = 0 et k(3) = 6

Étape 1 — Calcul de a

Formule\(a = \dfrac{6 - 0}{3 - (-1)} = \dfrac{6}{4} = \dfrac{3}{2}\)

Étape 2 — Calcul de b

On injecte \((-1\,;\,0)\) dans \(k(x) = \frac{3}{2}x + b\) : \(0 = \frac{3}{2} \times (-1) + b = -\frac{3}{2} + b\).

\(- \dfrac{3}{2}\) \(+ b = 0\)
\(+\dfrac{3}{2}\)
\(+\dfrac{3}{2}\)
\(b = \dfrac{3}{2}\)
\(k(x) = \dfrac{3}{2}x + \dfrac{3}{2}\). Vérif : \(k(3) = \frac{9}{2} + \frac{3}{2} = \frac{12}{2} = 6\) ✓

Exercice 5 / 5

Problème Synthèse complète
✓ Vu

Une cuve contient déjà de l'eau. On branche un robinet et on note le volume (en litres) toutes les quelques minutes :

Temps \(t\) (min) 2 5 10
Volume \(V\) (L) 16 34 64
1. Vérifier que \(V\) est bien une fonction affine de \(t\) (calculer \(a\) entre chaque paire de colonnes).
2. Donner la valeur de \(a\) et l'interpréter dans le contexte.
3. Trouver \(b\) et écrire \(V(t)\). Que représente \(b\) concrètement ?
4. Au bout de combien de minutes la cuve contiendra-t-elle 100 litres ? (méthode des flèches)

💡 Indices

Une fois \(a\) trouvé, écris \(V(t) = at + b\) et injecte le point \((2\,;\,16)\) pour trouver \(b\). Résous avec les flèches.
Pose \(V(t) = 100\), remplace par l'expression trouvée, et résous l'équation avec les flèches.
1. Vérification de l'affinité
Col. 1→2\(a = \dfrac{34-16}{5-2} = \dfrac{18}{3} = 6\)
Col. 2→3\(a = \dfrac{64-34}{10-5} = \dfrac{30}{5} = 6\)
Même coefficient directeur (\(a = 6\)) entre toutes les paires → \(V\) est bien une fonction affine de \(t\). ✓
2. Valeur et interprétation de a
\(a = 6\) litres par minute : c'est le débit du robinet. La cuve se remplit de 6 L à chaque minute.
3. Trouver b et écrire V(t)

On écrit \(V(t) = 6t + b\) et on injecte le point \((2\,;\,16)\) : \(16 = 6 \times 2 + b = 12 + b\).

\(b\) \(+ 12\) \(= 16\)

\(V(t) = 6t + 4\)
\(b = 4\) litres : c'est le volume initial déjà présent dans la cuve avant le branchement du robinet (\(t = 0\)).
4. Quand V(t) = 100 litres ?

On résout \(6t + 4 = 100\) :

\(6t\) \(+ 4\) \(= 100\)
