Exercice 1 — Calculer une expression

✓ Vu

Calculer pour $\textcolor{#1a6fa0}{x = 3}$ et $\textcolor{#c0392b}{y = -2}$ :

a) $A = 5x - 7$
b) $B = 3x^2 + 2x - 1$
c) $C = 4(2x + y) - 3y$
🔎 Remplace chaque lettre par sa valeur avec des parenthèses autour des nombres négatifs, puis respecte les priorités : puissances → × → +/−.
$x$ remplacé $y$ remplacé puissances × puis +/−

a) $A = 5x - 7$

$A = 5 \times \textcolor{#1a6fa0}{3} - 7 = \textcolor{#b85c0b}{15} - 7 = \boxed{8}$

b) $B = 3x^2 + 2x - 1$

$B = 3 \times \textcolor{#1a6fa0}{3}^2 + 2 \times \textcolor{#1a6fa0}{3} - 1$
$B = 3 \times \textcolor{#6b3fa0}{9} + \textcolor{#b85c0b}{6} - 1 = \textcolor{#b85c0b}{27} + 6 - 1 = \boxed{32}$

c) $C = 4(2x + y) - 3y$

$C = 4(2 \times \textcolor{#1a6fa0}{3} + \textcolor{#c0392b}{(-2)}) - 3 \times \textcolor{#c0392b}{(-2)}$
$C = 4 \times \textcolor{#6b3fa0}{4} \textcolor{#b85c0b}{-(-6)} = \textcolor{#b85c0b}{16} + 6 = \boxed{22}$

Exercice 2 — Simplifier

✓ Vu

Simplifier les expressions :

a) $7 \times a$
b) $5 \times (2x - 1)$
c) $4x \times 5x$
d) $3a \times 2b \times 4a$
🔎 On supprime le $\times$ devant une lettre ou une parenthèse. On réorganise : nombres ensemble, lettres ensemble. $x \times x = x^2$.
a) $7 \times a = \textcolor{#1b7a40}{7a}$
b) $5 \times (2x - 1) = \textcolor{#1b7a40}{5(2x - 1)}$
c) $\textcolor{#1a6fa0}{4}x \times \textcolor{#c0392b}{5}x = \textcolor{#1a6fa0}{4} \times \textcolor{#c0392b}{5} \times x \times x = \textcolor{#1b7a40}{20x^2}$
d) $\textcolor{#1a6fa0}{3}a \times \textcolor{#c0392b}{2}b \times \textcolor{#6b3fa0}{4}a = \textcolor{#1a6fa0}{3} \times \textcolor{#c0392b}{2} \times \textcolor{#6b3fa0}{4} \times a^2 \times b = \textcolor{#1b7a40}{24a^2b}$

Exercice 3 — Réduire

✓ Vu

Réduire lorsque c'est possible :

a) $7x + 2x$
b) $5x + 3y$
c) $3x + 7 + 5x - 2$
d) $2x^2 + 5x - 3x^2 + x - 8$
🔎 On ne réduit que des termes de même nature : $x$ avec $x$, $x^2$ avec $x^2$, constantes entre elles. Repère-les avec des couleurs.
a) $\textcolor{#1a6fa0}{7x} + \textcolor{#1a6fa0}{2x} = \textcolor{#1b7a40}{9x}$
b) $5\textcolor{#1a6fa0}{x} + 3\textcolor{#c0392b}{y}$ → non réductible
c) $\textcolor{#1a6fa0}{3x} + \textcolor{#c0392b}{7} + \textcolor{#1a6fa0}{5x} \textcolor{#c0392b}{- 2} = \textcolor{#1b7a40}{8x + 5}$

d) $2x^2 + 5x - 3x^2 + x - 8$

en $x^2$ en $x$ constantes
$\textcolor{#6b3fa0}{2x^2} + \textcolor{#1a6fa0}{5x} \textcolor{#6b3fa0}{- 3x^2} + \textcolor{#1a6fa0}{x} \textcolor{#c0392b}{- 8}$
$= \textcolor{#6b3fa0}{(2 - 3)x^2} + \textcolor{#1a6fa0}{(5 + 1)x} \textcolor{#c0392b}{- 8}$
$= \textcolor{#1b7a40}{-x^2 + 6x - 8}$

Exercice 4 — Programme de calcul

✓ Vu

Voici un programme de calcul :

① Choisir un nombre
② Multiplier par 3
③ Ajouter 5
④ Multiplier le résultat par 2

1. Appliquer ce programme au nombre $4$.

2. Appliquer ce programme au nombre $-1$.

3. On note $x$ le nombre de départ. Exprimer le résultat en fonction de $x$, puis simplifier.

🔎 Suis le programme avec $x$. À l'étape ④, tu multiplies toute l'expression par 2 : développe $2(3x + 5)$.

1. Avec $\textcolor{#1a6fa0}{4}$ :

$\textcolor{#1a6fa0}{4} \xrightarrow{\times 3} 12 \xrightarrow{+5} 17 \xrightarrow{\times 2} \boxed{34}$

2. Avec $\textcolor{#c0392b}{-1}$ :

$\textcolor{#c0392b}{-1} \xrightarrow{\times 3} -3 \xrightarrow{+5} 2 \xrightarrow{\times 2} \boxed{4}$

3. Avec $\textcolor{#6b3fa0}{x}$ :

$\textcolor{#6b3fa0}{x} \xrightarrow{\times 3} 3x \xrightarrow{+5} 3x + 5 \xrightarrow{\times 2} 2(3x + 5)$

On développe :

$\textcolor{#1a6fa0}{2}(\textcolor{#c0392b}{3x} + \textcolor{#6b3fa0}{5}) = \textcolor{#1a6fa0}{2} \times \textcolor{#c0392b}{3x} + \textcolor{#1a6fa0}{2} \times \textcolor{#6b3fa0}{5}$
Le résultat du programme est $6x + 10$.

Vérification : $x = 4$ → $34$ ✓ — $x = -1$ → $4$ ✓

Exercice 5 — Périmètre et aire

✓ Vu

Un rectangle a pour longueur $(5x + 3)$ cm et pour largeur $2x$ cm, avec $x > 0$.

1. Exprimer le périmètre en fonction de $x$. Réduire.

2. Exprimer l'aire en fonction de $x$. Simplifier.

3. Calculer le périmètre et l'aire pour $x = 4$.

🔎 Périmètre = $2 \times L + 2 \times \ell$. Développe puis réduis.
✏️ Aire = $L \times \ell$. Développe $2x(5x + 3)$.

1. Périmètre

$P = 2(5x + 3) + 2 \times 2x$
$P = \textcolor{#1a6fa0}{2} \times \textcolor{#c0392b}{5x} + \textcolor{#1a6fa0}{2} \times \textcolor{#6b3fa0}{3} + 4x = 10x + 6 + 4x$
$P = \textcolor{#1a6fa0}{10x + 4x} + 6$
$P = 14x + 6$ cm

2. Aire

$\mathcal{A} = \textcolor{#1a6fa0}{2x}(\textcolor{#c0392b}{5x} + \textcolor{#6b3fa0}{3}) = \textcolor{#1a6fa0}{2x} \times \textcolor{#c0392b}{5x} + \textcolor{#1a6fa0}{2x} \times \textcolor{#6b3fa0}{3}$
$\mathcal{A} = 10x^2 + 6x$ cm²

3. Pour $x = 4$ :

$P = 14 \times \textcolor{#1a6fa0}{4} + 6 = 56 + 6 = \boxed{62 \text{ cm}}$
$\mathcal{A} = 10 \times \textcolor{#1a6fa0}{4}^2 + 6 \times \textcolor{#1a6fa0}{4} = 160 + 24 = \boxed{184 \text{ cm}^2}$

Exercice 6 — Vrai ou faux ?

✓ Vu

Justifier chaque réponse.

Affirmation 1 : « $3x + 5x^2$ peut se réduire en $8x^3$. »

Affirmation 2 : « Quand $x = -3$, l'expression $x^2$ est négative. »

Affirmation 3 : « Les expressions $5(x + 2)$ et $5x + 2$ sont égales pour tout $x$. »

🔎 Pour prouver qu'une affirmation est fausse, un seul contre-exemple suffit. Pour la prouver vraie, utilise les règles du cours.

Affirmation 1 : FAUX ❌

$3\textcolor{#1a6fa0}{x}$ et $5\textcolor{#6b3fa0}{x^2}$ ne sont pas de même nature : on ne peut pas les additionner.

Contre-exemple : pour $x = 2$, $6 + 20 = 26$ mais $8 \times 8 = 64$.

$3x + 5x^2$ n'est pas réductible.

Affirmation 2 : FAUX ❌

$x^2 = \textcolor{#c0392b}{(-3)}^2 = (-3) \times (-3) = \textcolor{#1b7a40}{+9}$
Un carré est toujours positif (ou nul).

Affirmation 3 : FAUX ❌

Contre-exemple avec $\textcolor{#1a6fa0}{x = 1}$ :

$5(\textcolor{#1a6fa0}{1} + 2) = 5 \times 3 = \textcolor{#6b3fa0}{15}$
$5 \times \textcolor{#1a6fa0}{1} + 2 = 5 + 2 = \textcolor{#6b3fa0}{7}$
$15 \neq 7$. En réalité : $5(x + 2) = 5x + 10 \neq 5x + 2$.
